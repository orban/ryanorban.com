#   ai-input  real-time use in generative answers — RAG, grounding, answer engines
#   ai-train  training or fine-tuning a model
#
# yes = permitted, no = not permitted, absent = no preference. These are stated
# preferences and carry no technical force; the Disallow rules below are what bind.
#
# Agent index: /llms.txt (llmstxt.org). robots.txt has no directive for it, so this
# comment is the only pointer -- it is not in <head> or the sitemap either.
#
# The signal is repeated in every group that is allowed to crawl. Under RFC 9309 a
# crawler evaluates only its single most-specific matching group, so a signal declared
# once under User-agent: * would never reach GPTBot or OAI-SearchBot, which have groups
# of their own. Cloudflare's managed file declares it once, but every specific group it
# writes is a Disallow: / where the signal is moot. Ours are allow groups. The spec is
# silent on inheritance; repeating costs nothing and removes the ambiguity.

User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=yes
