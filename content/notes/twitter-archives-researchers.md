## Summary

In 2013, Twitter data was the canonical corpus for computational social science, natural language processing research, and social network analysis. The platform's public API allowed academic researchers to collect tweets at scale, and several groups had assembled and shared large datasets for reproducible research. This DataScholars post catalogued available Twitter archives — ranging from samples of the full firehose to topic-specific collections around events like the 2012 US presidential election, major disasters, and breaking news events.

The research use cases were numerous: sentiment analysis on public opinion, topic modeling on news cycles, network analysis of information diffusion and retweet cascades, crisis informatics (how emergency information spreads during disasters), bot detection, and language modeling on natural social media text. Twitter data had properties that made it scientifically interesting: timestamped, geolocated (sometimes), networked (follow/retweet graph), and representing real human communication at scale.

The 2013 open Twitter data ecosystem is worth noting in historical context. Twitter's API was genuinely permissive compared to later versions — researchers could access the Academic Research track and collect substantial samples. The TREC Microblog tracks (2011-2015) used Twitter data as evaluation corpora. By 2023, Elon Musk's API pricing changes had effectively ended the open academic Twitter research ecosystem — the datasets from 2013 represent a now-closed window of open social media data.

## Key points

- Twitter API (2013 era): relatively permissive academic access enabled researchers to build large public datasets — a now-closed era.
- Computational social science: Twitter as a laboratory for studying information diffusion, opinion formation, and social network dynamics at scale.
- TREC Microblog: competitive evaluation track using Twitter data — drove research on real-time information retrieval and event detection.
- Sentiment analysis at scale: Twitter's informal, opinionated text made it a standard benchmark for NLP sentiment models.
- Historical note: the open Twitter data ecosystem largely ended with API pricing changes in 2023 — 2013-era datasets are now archival resources.
