## Summary

Magnetic core memory was the dominant form of computer memory from the mid-1950s through the 1970s — before DRAM and SRAM made it obsolete. It worked by threading tiny ferrite rings (magnetic cores) on a grid of wires; a core's magnetic polarity represented a 0 or 1. It was hand-woven, tediously slow to manufacture, and remarkable in that it was non-volatile — it retained data without power. The Apollo Guidance Computer used core memory; so did the IBM System/360.

The Core Memory Shield project revived this technology as an Arduino shield — a board that plugs directly onto an Arduino microcontroller and gives it a working, functional magnetic core memory store. The shield held a few hundred bits (not kilobytes — bits) of actual woven core memory, functional and readable. The project was part nostalgia, part educational artifact, and part maker community performance art: building something from first principles that the industry had abandoned 40 years ago.

The appeal in 2012 was layered. The Arduino ecosystem had created an audience of hobbyists and engineers who liked understanding hardware at a fundamental level. Core memory represented a kind of computing archaeology — a technology so hands-on you could literally see the individual memory cells. The contrast with modern NAND flash or DDR4 DRAM (billions of invisible transistors on a chip) couldn't be starker. It connected the maker movement's interest in physical, tangible computing with the history of how computers actually worked.

## Key points

- Magnetic core memory was the standard computer memory from ~1955–1975, used in Apollo, IBM mainframes, and minicomputers.
- Non-volatile by nature: retains data without power, unlike modern DRAM (which needs constant refresh).
- The Core Memory Shield connected this vintage technology to modern Arduino microcontrollers — bridging 50 years of computing history.
- Capacity was measured in bits, not megabytes — a reminder of how far memory technology has traveled.
- The project circulated in hardware hacker and retro-computing communities, including discussion at events like Supercon.
- Manufacturing process: ferrite rings hand-threaded on wires — one reason it was expensive and labor-intensive before transistors made it obsolete.
