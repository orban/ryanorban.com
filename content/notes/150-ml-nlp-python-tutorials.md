## Summary

Robbie Allen compiled this extensive list of machine learning, NLP, and Python tutorials on Medium, organized by topic. For 2020, it captured the best freely available learning resources across the ML stack — from beginner Python to advanced deep learning and NLP techniques.

The organization covers: Python fundamentals → data wrangling (pandas, NumPy) → data visualization → statistics → machine learning fundamentals → deep learning → NLP → advanced topics. Each section includes both conceptual introductions and hands-on practical tutorials, with notes on what each covers. The NLP section is particularly comprehensive for its time — it covers word embeddings (word2vec, GloVe), recurrent models, attention, and the emerging transformer architecture (pre-GPT-3 era).

The value is curation — the internet has more ML tutorials than anyone could read, and the signal-to-noise ratio is low. A curated list from someone who has read them all and provides commentary on what each covers is significantly more useful than a raw search result. Allen's commentary helps readers know which resources are appropriate for their current level.

## Key points

- 150+ curated tutorials organized by topic: Python → data wrangling → statistics → ML → deep learning → NLP.
- Each entry includes commentary — not just links but context on content and appropriate SKILL level.
- Comprehensive NLP coverage for 2020: embeddings, RNNs, attention, early transformers.
- Complementary to ML Roadmap, Top ML Books, Best Data Science Books in the vault.
- High curation value: large volume of ML tutorials exists; filtered lists are more useful than raw searches.
