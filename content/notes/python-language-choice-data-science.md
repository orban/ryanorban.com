## Summary

Mikio Braun (machine learning researcher) traces the historical inflection point where Python eclipsed MATLAB in scientific computing and data science. The catalyst was unexpectedly administrative: around 2005, MathWorks changed its licensing policies, making MATLAB prohibitively expensive for publicly funded research institutes outside universities. The Fraunhofer Institute FIRST, where Braun worked, suddenly needed an alternative.

The key social moment was the 2005 Machine Learning Tools Satellite Workshop before NIPS. Rather than fragmenting across different alternatives, the community converged on Python. What mattered wasn't just the language itself but the confidence that adoption wouldn't leave researchers isolated — that others were making the same choice. NumPy, Matplotlib, and Python bindings for tools like Shogun already existed, providing the minimum viable ecosystem.

scikit-learn and pandas came later and solidified the choice, but the decision was effectively made at the 2005 NIPS workshop. Braun's key insight: "the infrastructure and set of available toolkits is at least as important as the language." Python won because its ecosystem grew faster, not because of inherent language superiority.

## Key points

- MATLAB dominated scientific computing and ML prototyping circa 2000. Python became the alternative after 2005 licensing changes made MATLAB expensive for non-university research.
- The 2005 NIPS ML Tools Satellite Workshop was the social tipping point — community consensus formed around Python.
- Early tools: NumPy, Matplotlib, Shogun Python bindings — enough of an ecosystem to make the switch viable.
- scikit-learn and pandas came later but cemented Python's position.
- Critical insight: tooling ecosystem matters as much as language design for community adoption.
- The R vs Python debate in data science is downstream of this 2005 decision.
