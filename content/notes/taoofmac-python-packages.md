## Summary

Tao of Mac is Rui Carmo's long-running personal site covering development tools, macOS, and technology with a practitioner's eye. His Python packages page is a curated, annotated list of libraries organized by domain — not an exhaustive index but a "these are worth knowing about" reference that reflects years of actual use.

The value of curated package lists over raw PyPI search: PyPI has hundreds of thousands of packages, many abandoned or poorly maintained. A practitioner's curated list surfaces libraries that are actually used in real projects, have reasonable maintenance status, and solve real problems. Rui Carmo's tastes run toward practical, low-dependency tools that solve specific problems cleanly.

Categories typically covered in such lists: CLI tools, data processing (pandas, polars, dask), HTTP clients (httpx, requests), async frameworks (asyncio utilities), testing (pytest plugins), type checking and linting, serialization, configuration management, and general utilities that fill gaps in the standard library. The "terseness and amazing flexibility" framing in the content description reflects a Python philosophy that values doing more with less code.

Tao of Mac has been running since the early 2000s — the site predates most modern Python tooling, giving it historical depth alongside current recommendations.

## Key points

- Rui Carmo (Tao of Mac): practitioner curation, not exhaustive cataloging — "these are worth knowing"
- Complements PyPI search by surfacing maintained, battle-tested libraries over raw popularity
- Python's terseness + flexibility thesis: the language reward is in combining small, composable libraries
- Site has historical depth (early 2000s origin) — can trace how Python tooling evolved over two decades
- Useful for discovering quality alternatives to obvious choices: what httpx is to requests, what polars is to pandas
