## Summary

Daniel Bourke (mrdbourke) created this visual machine learning roadmap as a community resource for people entering the field. The roadmap connects the key concepts — mathematics foundations (linear algebra, calculus, statistics/probability), programming tools (Python, NumPy, pandas), core ML algorithms (supervised learning, unsupervised learning, deep learning), and practical frameworks (scikit-learn, PyTorch, TensorFlow) — into a structured learning progression.

The value of a well-designed roadmap is giving learners an oriented view of a large, fragmented field. Machine learning as a discipline has hundreds of sub-topics, algorithms, and frameworks. Without guidance, self-learners often either start with the wrong fundamentals (skipping math and going straight to Keras) or get lost in theoretical depth (six months of textbooks before writing a line of code). Bourke's roadmap is opinionated about ordering in a way that reflects what actually matters for practitioners.

The GitHub repository includes links to specific resources for each concept on the map. This makes it a curated learning path rather than just a diagram — each node maps to concrete books, courses, or tutorials.

## Key points

- Visual roadmap connecting ML concepts into a structured learning progression, from math foundations to frameworks.
- Opinionated ordering: math → Python/tools → classical ML → deep learning → production.
- Each node links to specific resources — it's a curated path, not just a concept map.
- By Daniel Bourke (mrdbourke), a YouTube educator known for practical ML tutorials.
- 2020 edition reflects the dominant tools of that era: scikit-learn, PyTorch, TensorFlow, [fast.ai](/notes/fastai/).
- Related resources in vault: Top ML Books, 150+ ML tutorials, Best Data Science Books.
