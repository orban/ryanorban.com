## Summary

Inkplate 6PLUS is a Crowd Supply hardware project from Soldered Electronics — a development board combining an ESP32 microcontroller with a recycled 6-inch e-ink touchscreen display (1024×758 resolution), WiFi, Bluetooth, a microSD card slot, and built-in battery management. It's designed for maker projects that need a low-power, always-readable display: dashboards, e-readers, information displays, badges, digital signage.

The appeal of e-ink for projects is its power characteristics: unlike LCD or OLED displays, e-ink only consumes power when the screen content changes. A battery-powered Inkplate device can update its display hourly and run for weeks on a single charge. The 6-inch 1024×758 touchscreen is large enough for readable text and small graphics.

Inkplate boards are distinguished from raw e-ink displays by the built-in integration work: Soldered wrote Arduino and MicroPython libraries that abstract the complex timing and initialization sequences that e-paper displays require, making it accessible for projects without deep display driver experience. The Crowd Supply crowdfunding model means these hardware projects get built to order rather than requiring minimum order quantities.

Typical use cases: room dashboards showing calendar/weather, low-power IoT status displays, custom e-readers, conference badges, inventory labels, and solar-powered outdoor information displays.

## Key points

- ESP32 + e-ink touchscreen (1024×758) + WiFi + battery management — complete in one board.
- E-ink's key property: near-zero power when static — runs weeks on battery if content updates infrequently.
- Arduino and MicroPython libraries make display programming accessible without deep driver knowledge.
- 6PLUS adds touchscreen capability over earlier Inkplate models — enables interactive projects.
- Crowd Supply hardware: well-suited for maker community projects and small-batch custom devices.
