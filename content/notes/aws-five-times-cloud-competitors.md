## Summary

Gartner's 2013 analysis found Amazon Web Services had deployed five times more IaaS capacity than the next 14 cloud providers combined. ReadWrite reported on this, and the number spread quickly as shorthand for AWS won — the cloud infrastructure market was more lopsided than almost any other enterprise technology market.

The AWS advantage by 2013 had several compounding sources. First-mover advantage: AWS launched in 2006, giving them seven years to build infrastructure, refine operations, and drive down unit costs. Jeff Bezos ran AWS at near-zero margins deliberately to prevent competitors from scaling. Their EC2, S3, and adjacent services became the default platform for startups, creating a strong network effect — tooling, documentation, hiring pools, and third-party integrations all developed around AWS. Microsoft Azure launched in 2010, Google Cloud Platform in 2013 — both years behind in both capacity and ecosystem maturity.

The five-times figure proved durable: AWS maintained cloud market share leadership through at least 2023, though Microsoft and Google gradually closed the gap as they committed serious organizational investment. What the 2013 moment captured was the window before those companies fully mobilized — both still treated cloud as a secondary business.

## Key points

- AWS 5x capacity lead in 2013: result of 7-year first-mover advantage, deliberate margin sacrifice, and ecosystem lock-in via startups.
- Economies of scale flywheel: more customers → lower unit costs → lower prices → more customers — Amazon's classic reinvestment loop applied to infrastructure.
- Startup ecosystem lock-in: AWS tooling, tutorials, and talent were far ahead; new companies defaulted to AWS without evaluating alternatives.
- Microsoft Azure and Google Cloud Platform were the main challengers but years behind on both capacity and ecosystem depth.
- The 5x figure became a persistent narrative even as competitors grew — it established the mental model of AWS dominance that shaped cloud strategy for years.
- Historical context for hyperscale infrastructure investment: the cost of building competitive cloud scale is effectively a decade-long commitment.
