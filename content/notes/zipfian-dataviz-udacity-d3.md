## Summary

Zipfian Academy launched a free data visualization course on Udacity in November 2014, extending its in-person bootcamp curriculum to a broader online audience. The course (ud507) taught D3.js-based interactive graphics — the dominant framework for web-based data visualization at the time.

D3.js (Data-Driven Documents) was created by Mike Bostock at the New York Times and had become the standard for bespoke interactive charts on the web. It operates by binding data to DOM elements and applying transformations — a programming model that is powerful but has a steep learning curve. Bootcamp-style instruction was one of the better ways to learn it, since D3's API is large and the learning curve doesn't reward reading documentation alone.

The Udacity collaboration was part of a broader pattern: coding bootcamps partnering with MOOCs to reach students who couldn't afford or attend in-person programs. Ryan Orban (Zipfian co-founder) was involved in producing the curriculum. This course represented Zipfian Academy's curriculum going public — the same material that in-person students were paying for was being released free online.

## Key points

- November 2014: Zipfian Academy launches data visualization MOOC on Udacity (course ud507).
- Curriculum centered on D3.js — the web-native JavaScript library for interactive, data-driven graphics.
- D3.js created by Mike Bostock at NYT — binds data to DOM elements and applies SVG transforms.
- Free online release of Zipfian's in-person bootcamp curriculum — part of bootcamp-to-MOOC trend.
- Udacity's model: brief video lectures + interactive exercises + projects, optimized for self-paced online learning.
- Preceded by Zipfian's acquisition by Galvanize the same month — curriculum lives on through the merged entity.
