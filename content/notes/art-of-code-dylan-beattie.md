## Summary

Dylan Beattie's talk *The Art of Code* explores programming as a creative medium rather than a purely instrumental one. The talk moves through esoteric programming languages (including Rockstar, a language where programs are valid rock lyrics), code golf (writing programs in the fewest possible characters), quines (programs that output their own source code), musical programming languages, and the subset of programmers who treat code as an art form.

The argument Beattie makes is subtle: the same substrate that runs mission-critical banking software and hospital systems also supports programs that play chess using ASCII art and programs where the code itself is a poem. Both are real expressions of what software is. The artistic fringe of programming keeps the field honest about what code actually is — expressive notation that humans write for other humans, which also happens to run on machines.

The talk is a good cultural artifact of developer conference culture circa 2019–2020, when there was still strong appetite for talks that celebrated the weird and wonderful corners of the field. For practitioners who think of programming as purely professional, it serves as a useful corrective — a reminder that the people who built the languages, tools, and conventions underlying professional software were often playing and exploring, not just solving business problems.

## Key points

- Esoteric programming languages like Brainfuck, Malbolge, and Rockstar reveal what a programming language actually requires at its minimum.
- Quines — programs that print their own source code — force deep thinking about self-reference and fixed points in computation.
- Code golf optimizes for brevity rather than readability, exposing the structure of algorithms in compressed form.
- Software has always had an artistic and playful dimension alongside the commercial — the history of computing culture reflects both.
- By Dylan Beattie, creator of Rockstar programming language and regular conference speaker.
