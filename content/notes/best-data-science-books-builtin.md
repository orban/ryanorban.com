## Summary

Built In compiled this data science book list with expert commentary, organized by category and learning stage. Unlike pure ML books lists, this covers the full data science stack: statistics and probability foundations, Python programming, data manipulation, machine learning, and communication/storytelling with data.

The categorization is useful: introductory statistics texts (Naked Statistics, Think Stats) are separated from rigorous ML theory texts (ESL, PRML), and practical implementation books (Python for Data Analysis, Hands-On ML) are distinguished from conceptual ones (The Art of Statistics). This layering helps readers understand what to read at what stage rather than getting overwhelmed by a flat list.

Notable entries specific to the data science orientation (vs. pure ML): Data Science for Business (Provost & Fawcett — connecting ML to business decisions), Storytelling with Data (Knaflic — data visualization communication), and Python for Data Analysis (Wes McKinney, the pandas creator). These reflect the broader SKILL set that distinguishes data scientists from ML researchers.

## Key points

- Organized by stage: foundations → implementation → advanced theory → communication.
- Data science scope: broader than ML — includes statistics, pandas-based data manipulation, visualization, and business communication.
- Notable entries: Storytelling with Data, Data Science for Business, Python for Data Analysis (Wes McKinney).
- Complementary to [Top ML Books 2020](/notes/top-ml-books-2020/) (more ML-theory focus) and 150+ ML tutorials (online resources).
- Expert commentary provides context for when each book is appropriate — useful for curating your own reading list.
