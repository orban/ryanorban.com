## Summary

[Made With ML](/notes/made-with-ml/) is a free curriculum by Goku Mohandas designed to teach machine learning from end to end — not just model training, but the full stack that takes a model into production. The course covers data engineering, feature engineering, model training, evaluation, deployment, and MLOps practices like testing, monitoring, and CI/CD for ML systems.

The pedagogical bet is that most ML courses teach you to build models but not to ship them. [Made With ML](/notes/made-with-ml/) starts from that observation and builds a curriculum around a single product — a project that you take from raw data to a deployed, monitored API. This project-first approach means everything taught has a concrete application.

The audience is practitioners with some Python background who want to become effective ML engineers rather than pure researchers. Topics like experiment tracking (with MLflow), data versioning, and model deployment with FastAPI are included alongside the standard ML content — making this one of the few resources that bridges the gap between Jupyter notebooks and production systems.

## Key points

- Full-stack machine learning curriculum: data → model → MLOps → deployment, not just modeling.
- Written by Goku Mohandas — free, project-based, regularly updated.
- Covers experiment tracking, data versioning, testing, and CI/CD for ML — often ignored in academic courses.
- Uses Python, PyTorch, FastAPI, MLflow, and DVC as the tech stack.
- Aimed at practitioners who need to ship, not just research.
