## Summary

[CatalyzeX](/notes/catalyzex/) is a Chrome extension that surfaces code repositories alongside ML research papers — directly in the browser, wherever you're reading. When you're on arXiv, Semantic Scholar, Google Scholar, NeurIPS proceedings, or other academic sites, [CatalyzeX](/notes/catalyzex/) injects "Code" buttons next to paper titles that link directly to the GitHub implementations. No separate search, no copy-pasting paper titles into Papers with Code.

The practical value is friction reduction. Papers with Code already built the link database between papers and implementations, but you had to navigate there separately. CatalyzeX brings those links to wherever you're already reading. For ML practitioners, the question does this paper have code? is one of the first things you want answered — if there's no implementation, you're either implementing it yourself or skipping it. The extension makes that answer immediate.

By 2022, Papers with Code had become the standard infrastructure for linking ML research to reproducible implementations. The dataset it built (paper → code mappings) was extensive enough to be genuinely useful. CatalyzeX added a browser layer on top, extending the benefit to more reading contexts. The extension is a good example of the ambient information pattern: making relevant metadata available exactly where you're doing the work, without requiring a context switch.

## Key points

- Chrome extension that adds "Code" buttons to ML papers across arXiv, Google Scholar, Semantic Scholar, NeurIPS
- Uses Papers with Code database of paper → implementation mappings
- Removes friction: "does this paper have code?" answered immediately, without navigating away
- Works across multiple academic platforms — not just arXiv
- Example of ambient information: relevant metadata surfaced in the context where you need it
- Complements Papers with Code by extending its database reach into the browser reading experience
