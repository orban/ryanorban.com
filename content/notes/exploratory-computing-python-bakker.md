## Summary

Mark Bakker (TU Delft) created this open course as a practical introduction to scientific computing with Python, targeting engineers and quantitative scientists rather than software developers. The course is distributed as a series of Jupyter notebooks covering NumPy, Matplotlib, and applied numerical methods — making it freely runnable and modifiable.

The approach is domain-driven: examples come from engineering and scientific contexts (differential equations, fluid mechanics, data fitting, signal processing) rather than general-purpose programming. This made it a useful complement to bootcamp-style data science courses in 2014, which tended to focus on pandas and machine learning without covering the scientific computing foundations that physical scientists needed.

The Jupyter notebook format (then still called IPython Notebook) was the key pedagogical choice: learners run the code, modify it, see results immediately, and build up from working examples. This is the literate programming approach to scientific education — code and explanation interleaved in a document that is both textbook and laboratory.

## Key points

- Mark Bakker, TU Delft — open educational resource targeting engineers and physical scientists.
- Built on Jupyter notebooks (then IPython Notebook) — executable, modifiable course material.
- Core stack: NumPy for array math, Matplotlib for visualization, SciPy for numerical methods.
- Domain examples: differential equations, linear systems, data fitting — scientific rather than business-focused.
- Free and open — hosted on GitHub Pages with no paywall.
- Complements bootcamp curricula that focused on Pandas + ML but skipped numerical computing foundations.
