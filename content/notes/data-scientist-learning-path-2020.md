## Summary

Analytics Vidhya published this structured learning path as a curriculum for self-taught data science aspirants. Analytics Vidhya is one of the largest data science education communities in India and globally, and their learning paths reflect the practical skills valued in industry hiring rather than academic completeness.

The path is organized as a linear curriculum: (1) Mathematics and statistics foundations (linear algebra, probability, statistics — specifically the applied subsets used in ML), (2) Python programming (syntax, NumPy, pandas, matplotlib/seaborn for data manipulation and visualization), (3) machine learning algorithms (scikit-learn, classical ML: regression, classification, clustering, ensemble methods), (4) advanced topics (deep learning with Keras/TensorFlow or PyTorch, NLP basics), and (5) applied projects for portfolio building.

The 2020 edition reflects the tool stack of that era: scikit-learn as the central ML framework, pandas for data manipulation, and early-stage deep learning frameworks. The analytics-focused framing (SQL, Power BI, Tableau) distinguishes it from more research-oriented paths — this is aimed at business-facing data science roles rather than ML research.

## Key points

- Analytics Vidhya curriculum aimed at industry data science roles, not ML research.
- Sequence: math/stats → Python/pandas → classical ML → deep learning → applied projects.
- Business analytics layer included: SQL, Tableau/Power BI — distinguishes from pure ML paths.
- Portfolio building via Kaggle competitions and real datasets is explicit in the path.
- Related vault notes: ML Roadmap (mrdbourke), Best Data Science Books, 150+ ML tutorials, 160 DS interview questions.
