## Summary

This Quora thread collected the data science blog ecosystem as it existed in 2013 — the primary informal learning channel for practitioners before structured MOOCs, YouTube channels, and platforms like Towards Data Science dominated. The recommended blogs spanned academic ML research, practitioner implementations, and business-focused analytics.

The prominent blogs of this era included Simply Statistics (Jeff Leek, Roger Peng, Rafa Irizarry — rigorous statistics with public health applications), Variance Explained (David Robinson — R tutorials with real data), Andrew Gelman's blog (Statistical Modeling, Causal Inference, and Social Science), yhat's blog (Python ML applied to business problems), and Flowing Data (Nathan Yau — data visualization). The Stochastic Gradient blog was cited for ML theory; No Free Hunch was Kaggle's official blog for competition insights.

This ecosystem of practitioner-written blogs was the primary knowledge transfer mechanism for a generation of data scientists who learned between 2011 and 2015. Faster than books, more honest than vendor documentation, more practical than academic papers — blogs with working code in R or Python were how skills propagated through the community. The tweet sharing this thread mentioned McGrory, Dietrich, and the DataScience hashtag — the community was small enough that most influential practitioners knew each other.

## Key points

- Simply Statistics (Leek/Peng/Irizarry): rigorous statistics education for practitioners — reproducibility, p-value interpretation, data sharing — influential in setting norms.
- Andrew Gelman's blog: Bayesian statistics, model criticism, and social science applications — the best statistician's blog on the internet in 2013.
- Flowing Data (Nathan Yau): data visualization tutorials and commentary — the visual counterpart to the analytical blogs.
- Kaggle blog (No Free Hunch): competition retrospectives from top competitors — learning how winners approached feature engineering and model selection.
- yhat / R-bloggers: practitioner Python and R content — working code, not theory.
- Historical note: this blog ecosystem mostly migrated to Medium/Towards Data Science by 2017-2018; many original blogs went quiet as Twitter absorbed the real-time technical conversation.
