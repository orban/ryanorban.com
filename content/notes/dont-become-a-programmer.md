## Summary

Zed Shaw — creator of Learn Python the Hard Way and Learn Code the Hard Way — published this post as a direct counterweight to the everyone should learn to code messaging coming from Codecademy, Code.org, and similar initiatives. Shaw's argument: people were flocking to programming as a career path because they heard the salaries were good and it was meritocratic, not because they were intrinsically motivated by the craft. That's a bad reason, and it produces bad programmers.

The post is deliberately provocative. Shaw's actual teaching philosophy (from his books) is that learning to code requires sustained grinding, daily practice, and genuine curiosity — none of which you sustain if your only motivation is career advancement. The Learn Code the Hard Way curriculum is built on this: it's boring by design, because the point is to develop the habit and the muscle before you care about being productive. If you don't love the early grind, you won't love the later work.

The wider point Shaw was making: the rush to declare programming a universal SKILL was partly driven by economic interests (bootcamp businesses, tech company recruitment pipelines) and partly by tech culture's evangelism. Neither of those interests aligned with honestly representing what it takes to become a good programmer, or who it's actually a good fit for. This is a position he's expanded in later writing about how the tech industry over-recruited, burned people out, and failed to deliver the promised careers to many bootcamp graduates.

## Key points

- Intrinsic motivation is the only reliable fuel for the sustained learning programming requires.
- Zed Shaw's Learn Code the Hard Way curriculum is deliberately hard because grinding is the actual mechanism of learning.
- The 2012 code as career move wave was partly driven by bootcamp business interests misaligning with student outcomes.
- Contrast with the coding literacy position (everyone should script, not everyone should be a professional dev).
- Shaw's later writing: the industry over-hired, and many who learned coding for career reasons burned out or didn't find the promised jobs.
