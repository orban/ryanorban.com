## Summary

Stamen Design launched Map Stack as a tool that made customizing and compositing web map tile layers accessible to anyone, not just developers with deep Leaflet or Mapbox expertise. The interface worked like a layer editor: choose a base map, stack additional tile layers (terrain, labels, boundaries, satellite), adjust opacity and blend modes, and export the result as a shareable URL or image. It democratized the kind of cartographic design that previously required custom TileMill setups or GIS expertise.

Stamen Design was already known for their landmark cartographic work — Toner, Terrain, and Watercolor tile styles were widely used as alternatives to Google Maps' default aesthetic. Map Stack let anyone combine Stamen's styles with other tile providers into custom compositions. The output was primarily aesthetic (beautiful maps for presentations, journalism, art) rather than functional (routing, geocoding).

The broader significance: 2013 was when map design moved from server-side GIS rendering to web tile compositing, making it a design problem as much as a technical one. Tools like Map Stack, Mapbox Studio, and CartoDB (now CARTO) were part of this shift — maps as a medium for communication and design, not just navigation.

## Key points

- Layer-based compositing of web map tiles — blend, stack, and adjust opacity like Photoshop layers
- Built on Stamen Design's open tile styles: Toner (black/white), Terrain, Watercolor
- Outputs shareable URLs and static images — designed for journalists, designers, and non-developers
- Part of the 2013 wave of web mapping tools democratizing cartographic design
- Stamen Design pioneered beautiful, opinionated map aesthetics as an alternative to Google Maps' utility-first approach
- MapStack itself has since been discontinued, but its design philosophy influenced Mapbox GL Style Spec
