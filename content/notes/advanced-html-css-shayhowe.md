## Summary

Shay Howe's Advanced HTML & CSS guide was part of a two-part free online course on modern web development. The introductory course covered HTML structure and basic CSS; this advanced guide covered topics that were pushing the frontier of web development in 2013: complex CSS selectors, CSS transitions and animations, CSS transforms, responsive design with media queries, web performance, and preprocessors like [Sass](/notes/sass/).

The 2013 context is important: responsive design was relatively new (Ethan Marcotte's foundational article appeared in 2010, his book in 2011), and many developers were still figuring out how to structure CSS for multi-device layouts. The guide was useful because it synthesized current best practices in an accessible, free format at a time when most comparable resources were either books, expensive courses, or scattered across blog posts.

Shay Howe was then at ENVY Labs (now [Code School](/notes/code-school/)). The guide became widely recommended in web development communities as a reference for developers who knew basic HTML/CSS and wanted to level up. It was later updated and supplemented with additional chapters as the web platform evolved.

## Key points

- Responsive design: media queries to adapt layout to viewport width — the dominant approach to multi-device web in 2013
- CSS transitions / animations: hardware-accelerated visual effects without JavaScript — browser support was new and inconsistent in 2013
- CSS transforms: translate, rotate, scale, skew — the foundation for modern CSS animation
- [Sass](/notes/sass/): CSS preprocessor adding variables, nesting, mixins — mainstream by 2013, precursor to the CSS features now natively supported
- Historical note: this guide predates CSS Grid, CSS custom properties (variables), and most of what's now considered basic CSS
