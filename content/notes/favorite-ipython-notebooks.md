## Summary

This Prismatic share (the original URL is dead) pointed to a curated list of seven exemplary IPython Notebooks — shared at a moment when the notebook format was becoming the dominant medium for communicating data science work. IPython Notebook (renamed Jupyter in 2014 and later expanded to support Julia and R) let practitioners interleave code, prose, math, and visualizations in a single shareable document.

In 2013-2014, notable notebook collections were circulating that demonstrated the format's potential: Jake VanderPlas's scikit-learn tutorial notebooks (including the validation notebook already in this vault), Fernando Perez's signal processing demos, Cyrille Rossant's "Introduction to Applied Bioinformatics", Brian Granger's physics simulations, and community favorites like a probabilistic programming walkthrough and data visualization tutorials using D3.js via Python-to-JS bridges.

The curated list format was itself characteristic of the era: before organized notebook repositories like Kaggle Kernels, GitHub Gist, or nbviewer, discovery depended on word-of-mouth sharing through Twitter, Prismatic, and personal blogs. nbviewer (launched 2013) was the tool that made sharing notebooks with non-technical audiences practical — GitHub rendered them as static HTML, but nbviewer handled all the math and visualization rendering.

## Key points

- IPython Notebook → Jupyter: renamed and generalized to Julia/Python/R in 2014 — the kernel architecture enabled multi-language notebooks.
- nbviewer: the service that made sharing notebooks practical — rendered GitHub-hosted notebooks as static HTML with math and visualizations.
- Notebook as teaching medium: the interleaving of code and prose made the format ideal for tutorials where you want to show intermediate results.
- Curation era: before Kaggle Kernels and organized repositories, notebook discovery was through social sharing — lists like this one served as editorial filters.
- Jake VanderPlas and the PyCon notebook series were among the most-shared — setting the template for code-as-documentation in data science education.
