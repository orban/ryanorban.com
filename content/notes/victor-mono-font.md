## Summary

Victor Mono is a free, open-source monospace font designed for code by Rune Bjørnerås (rubjo). Its defining feature is the optional cursive style for italic characters — keywords, comments, and other italic-rendered elements in syntax-highlighted code appear in a semi-connected script style rather than the typical slanted upright form.

The cursive italics are divisive: some developers find them beautiful and visually separating (comments in cursive look clearly distinct from code), while others find them distracting or hard to read at a glance. The font ships with three variants: `Oblique` (slanted, no cursive), `Italic` (full cursive), and `Oblique Italic` — letting you choose how much cursive you want.

Victor Mono also includes ligatures (combining `->` into an arrow glyph, `!=` into a not-equal sign, etc.) and was designed with clear glyph differentiation — `0` vs `O`, `l` vs `1` vs `I` — which matters for programming. It works well in editors like VS Code, Neovim, and terminal emulators.

## Key points

- Cursive italic variant is the signature feature — keywords and comments look hand-written.
- Three style variants: standard, oblique (tilted), italic (cursive) — configurable per editor.
- Ligatures for common programming character sequences (arrows, comparisons, assignments).
- Free and open-source under the OFL (SIL Open Font License).
- Competes with Fira Code, JetBrains Mono, Cascadia Code in the programming font space.
- Available for VS Code, Neovim, iTerm2, and most modern development environments.
