## Summary

Input is a font family by David Jonathan Ross (DJR) designed from the ground up for writing and reading code. Unlike fonts adapted from text typefaces, Input was built specifically for the programming context: long sessions, variable-width identifiers, and the need to distinguish visually similar characters (0/O, 1/l/I, {/(), etc.).

The family is unusual for a coding font in offering both monospace and proportional variants. The proportional variant is designed for comments and documentation, where the fixed-width constraint isn't needed and proportional spacing is more readable. This lets you use different spacing modes for different purposes within the same file, and the font stays visually consistent.

Input ships with configurable letterform variants: four options each for the letter "a", "g", "i", "l", "0", and the braces/curly braces. You customize your version on the website before downloading, so the font you get matches your own legibility preferences.

## Key points

- Both monospace and proportional widths in a single coherent family — rare in programming fonts.
- Designed by David Jonathan Ross, a type designer known for large flexible font families.
- Configurable letterforms for ambiguous characters (0 vs O, i vs l, etc.) — download the variant that works for your eye.
- Free for personal use; commercial license for products.
- Sits alongside JetBrains Mono, Fira Code, and Iosevka in the serious coding-fonts space.
