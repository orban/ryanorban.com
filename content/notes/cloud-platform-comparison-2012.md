## Summary

By mid-2012, enterprises evaluating private cloud infrastructure faced a genuinely complex choice: OpenStack, CloudStack, Eucalyptus, and VMware vCloud Director each had different backers, different API designs, different operational characteristics, and different stories about their future. Network World's comparison tried to give IT decision-makers a framework for choosing.

OpenStack had the most industry momentum — backed by Rackspace, NASA, Red Hat, HP, IBM, and Canonical — but was the hardest to deploy and operate. Its loosely-coupled architecture made it flexible but demanding. CloudStack (acquired by Citrix in 2011, then donated to Apache in 2012) was considered more operationally mature and easier to deploy. Eucalyptus had a key differentiator: AWS-compatible APIs, meaning workloads could move between Eucalyptus private cloud and AWS public cloud without modification. vCloud Director was VMware's commercial offering — expensive, closed, but polished and backed by VMware's enterprise relationships.

The historical verdict: OpenStack won the private cloud war between these four competitors, but the entire private cloud category eventually lost to managed public cloud (AWS, Azure, GCP). Eucalyptus was eventually acquired by HPE; CloudStack remains an Apache project but is a niche player; vCloud Director survived as a VMware product line until Broadcom's 2023 acquisition changed VMware's strategy.

## Key points

- CloudStack: operationally simpler than OpenStack, eventually donated to Apache Foundation; backed by Citrix
- Eucalyptus: AWS-compatible APIs were its key differentiator — hybrid cloud before the term was common
- vCloud Director: VMware's commercial private cloud; polished but expensive and proprietary
- OpenStack: most institutional support but hardest to operate — won the competition among these four
- The 2012 private cloud competition was made moot by managed public cloud; AWS dominance wasn't yet obvious
