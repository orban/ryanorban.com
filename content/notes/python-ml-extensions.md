## Summary

This Prismatic/Strata piece surveyed the Python ecosystem for machine learning in late 2013 — a moment when the stack was consolidating but hadn't yet reached the tidiness of the post-2015 landscape. scikit-learn was ascendant but not yet dominant; NumPy and SciPy were established; pandas was relatively new (released 2011); matplotlib was standard for visualization but seaborn was just emerging.

The 2013 Python ML ecosystem was a patchwork: Theano for deep learning (before TensorFlow and PyTorch); NLTK for natural language processing; Gensim for topic models; statsmodels for econometric-style statistical modeling that scikit-learn didn't cover; PyMC for Bayesian inference. Each filled a gap, and knowing which library addressed which need was itself a valuable SKILL.

The broader context: R still had more statistical packages and was the default in academia, but Python's general-purpose nature made it better for production systems and data pipelines. The battle between R and Python for data science dominance was still live in 2013; Python had largely won it by 2016.

## Key points

- 2013 Python ML stack: NumPy + SciPy (numerics), pandas (data manipulation), scikit-learn (ML algorithms), matplotlib (visualization).
- Specialized libraries: Theano (deep learning), NLTK (NLP), Gensim (topic models), PyMC (Bayesian inference), statsmodels (statistical modeling).
- The stack was fragmented in 2013; knowing which library to use for which task was valuable knowledge.
- Python vs. R battle for data science dominance was unresolved — Python won decisively by ~2016.
