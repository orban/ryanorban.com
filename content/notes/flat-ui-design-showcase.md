## Summary

Flat UI Design (fltdsgn.com) was a curated gallery collecting examples of flat design applied to web and mobile interfaces — the aesthetic movement that was rapidly displacing skeuomorphism in 2013. The timing was significant: Apple still shipped iOS with skeuomorphic design (leather textures in Calendar, felt in Game Center, linen backgrounds), but the community had already moved. Microsoft's Metro design language in Windows Phone (2010) and Windows 8 (2012) had established flat design as a legitimate UI paradigm; Google's Holo design language for Android 4.0 (2011) moved in the same direction.

Flat design's core principles: remove gradients, shadows, bevels, and textures. Use solid colors, simple geometry, and whitespace. Let content be the visual focus rather than decorative chrome. Typography becomes more important when illustrations and icons can't rely on shading for definition. The aesthetic aligned with web performance (fewer HTTP requests for textures, smaller CSS) as much as aesthetics.

The gallery format — curating the best examples of an emerging aesthetic — was a common early 2010s mechanism for defining and spreading design movements before Dribbble's dominance. fltdsgn.com served as a reference for designers adopting flat style, showing both interface components (buttons, navigation bars, form fields) and complete app UI mockups. Apple's iOS 7 (June 2013) would later validate the movement by abandoning skeuomorphism entirely — this gallery predated that announcement by three months.

## Key points

- Flat design movement: removal of gradients, textures, shadows, and bevels from UI — content and typography do the design work, not decoration.
- Timeline: Metro (2010) → Holo (2011) → flat design community adoption (2012-13) → iOS 7 validation (June 2013) → Material Design codification (2014).
- Gallery as design canon: curated showcases defined what flat design meant before it had a formal spec — fltdsgn.com was part of this community standard-setting.
- Web performance alignment: solid colors and CSS instead of PNG textures improved load times — a practical justification alongside the aesthetic one.
- Skeuomorphism end: Jony Ive's influence at Apple after Scott Forstall's departure (late 2012) led directly to iOS 7's flat redesign.
