## Summary

[Sonic Pi](/notes/sonic-pi/) is a live coding music environment created by Sam Aaron at the University of Cambridge. You write code in a Ruby-like syntax that generates music — loops, samples, synths, effects — and changes you make to the code take effect on the next iteration, while the music continues playing. This is live coding in the most direct sense: your code is the instrument.

The tool was originally designed for teaching programming in UK schools using music as the motivating domain. Learning to code through live music creation turned out to be significantly more engaging than abstract exercises, and [Sonic Pi](/notes/sonic-pi/) developed a following in educational settings. But it also evolved into a legitimate live performance tool — artists perform entire shows using Sonic Pi, with the code projected on screen so audiences can see the music being written in real time.

The Hacker News discussion (1000+ points at posting time) reflects genuine enthusiasm from programmers who find the intersection of code and music compelling. Sonic Pi represents a broader category of creative coding environments — alongside Processing, p5.js, and SuperCollider — where the output is art or music rather than software.

## Key points

- Live coding music: modify code while it runs, changes take effect on the next loop iteration.
- Built on Ruby syntax with domain-specific extensions for music — loops, samples, synths, effects, time.
- Originated as a CS education tool for UK schools; became a serious live performance instrument.
- Part of the creative coding ecosystem alongside SuperCollider, Processing, p5.js.
- Open source; cross-platform; included by default on Raspberry Pi.
