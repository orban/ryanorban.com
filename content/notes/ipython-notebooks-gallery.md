## Summary

This GitHub wiki page curated a living list of interesting IPython Notebook (now Jupyter) examples across scientific computing, data analysis, machine learning, statistics, and visualization. In 2014, sharing executable notebooks was still novel — nbviewer existed but wasn't widely known, and most code examples were still posted as blog posts or scripts.

The gallery was a community resource that showed what notebooks could do: SciPy lectures, NumPy explorations, PyMC Bayesian examples, signal processing demos, and matplotlib visualization galleries all in one place. For learners, it was a sourcebook of executable, annotated examples from practitioners across scientific computing.

## Key points

- Organized by domain: statistics, machine learning, visualization, signal processing, physics, biology — a breadth that showed Python's reach
- Many entries link to IPython Notebook files on GitHub or nbviewer, making them directly runnable
- Includes foundational SciPy lecture notes from scientific Python conferences — high-quality teaching material
- PyMC examples in the gallery showed Bayesian inference in practice before PyMC3 existed
- The wiki format meant the list grew organically via community contributions — a 2014 equivalent of what Awesome lists later became
