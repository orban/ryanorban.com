## Summary

This GitHub repository contains materials from the Research Computing Fall 2013 meetup series — IPython Notebooks covering Python for scientific computing, data analysis, and high-performance computing (HPC) workflows. The series was aimed at researchers transitioning from MATLAB or R to Python for their computational work, covering the standard scientific Python stack: NumPy, SciPy, matplotlib, and tools for running jobs on clusters.

The meetup format — working through notebooks together — was an effective way to introduce researchers to tools they'd use in daily work without the overhead of a formal course. The notebooks remain useful as a snapshot of what practical Python for research looked like in late 2013.

## Key points

- Covers the core scientific Python stack: NumPy for arrays, SciPy for algorithms, matplotlib for visualization
- Includes parallel processing examples using multiprocessing and MPI bindings — relevant for research computing contexts
- Notebook format means examples are immediately runnable — a teaching approach that became standard after Jupyter grew in adoption
- HPC workflow examples show how to submit jobs and handle large datasets that don't fit in a single machine's memory
- A useful artifact of the early scientific Python community before Jupyter notebooks went mainstream at conferences and in courses
