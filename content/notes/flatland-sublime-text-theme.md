## Summary

Flatland is a dark flat design theme for Sublime Text created by Thinkpixellab. Released in early 2013, it arrived at the moment when flat design was displacing skeuomorphic design as the dominant aesthetic in software UIs — Apple would announce the iOS 7 flat redesign in June 2013, Microsoft had shipped Windows 8's flat Metro interface in 2012, and designers were rapidly moving away from gradients, shadows, and textures.

For developers, code editor themes are a surprisingly personal choice — you stare at them for 8+ hours a day, so minor decisions about syntax colors and sidebar chrome have an outsized effect on comfort and readability. Flatland's appeal was removing the visual noise of the default Sublime Text UI — the beveled sidebar, gradient title bar, and textured backgrounds — replacing them with solid colors and clean typography. It became one of the most-starred Sublime Text themes on GitHub in 2013.

The flat design trend in code editors paralleled the broader design industry shift. Solarized (2011) had already established that careful color theory mattered for code editors; Flatland applied flat design principles specifically to the Sublime Text chrome (sidebar, tabs, status bar) rather than just the syntax highlighting scheme.

## Key points

- Flat design applied to code editors: removes gradients and textures from the Sublime Text UI chrome — sidebar, tabs, status bar, file tree.
- 2013 timing: arrived alongside the flat design wave that peaked with iOS 7 (June 2013) and continued through Material Design (2014).
- Sublime Text dominance in 2013: Sublime was the default editor for many developers before Atom (2014) and VS Code (2015) emerged.
- Color palette: flat dark background with muted syntax colors — designed for long sessions, not showcase screenshots.
- Thinkpixellab: Seattle-based design/dev studio responsible for several influential open-source design tools.
