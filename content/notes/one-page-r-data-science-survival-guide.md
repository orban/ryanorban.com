## Summary

One Page R by Togaware (Graham Williams) is a living reference document for doing data science with R. Despite the one page name, it's a comprehensive guide covering the full workflow: data loading, transformation, exploration, modeling, and visualization. It was one of the primary community references for R-based data science in the early 2010s.

R was the dominant language for statistical analysis and data science before Python overtook it around 2015-2016. The ecosystem was rich — ggplot2 for visualization, dplyr for data manipulation, caret for machine learning — but scattered across many packages with inconsistent APIs. Reference documents like One Page R helped practitioners navigate the landscape without having to dig through package documentation every time.

The document reflects the pre-tidyverse era of R. The tidyverse (Hadley Wickham's collection of packages) later unified much of the R data science workflow under a coherent philosophy, but in 2014 the community was still in the heterogeneous package-of-packages phase.

## Key points

- Comprehensive R reference covering data loading, transformation, modeling, and visualization.
- Pre-tidyverse: reflects the older R ecosystem before dplyr, tidyr, and ggplot2 unified the workflow.
- Graham Williams maintains it — a living document updated as the R ecosystem evolved.
- R dominated data science in academia and statistics in 2014; Python was surging but not yet dominant.
- Pair with ggplot2 docs and Hadley Wickham's Advanced R for a complete picture.
