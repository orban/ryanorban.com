## Summary

This Prismatic story links to a tutorial on starting with machine learning in Python — covering the core libraries (Scikit-Learn, NumPy, Pandas) and basic workflow. In 2014, "how to get started with ML in Python" was a genuine question without a canonical answer: [fast.ai](/notes/fastai/) didn't exist yet, Coursera's ML course used MATLAB, and the Python ML ecosystem lacked consolidated beginner resources.

The Scikit-Learn documentation was the best technical reference but assumed familiarity with the concepts. NumPy and Pandas had similar documentation gaps for newcomers. Community tutorials like this filled the gap by showing end-to-end: load data with Pandas, preprocess, fit a Scikit-Learn model, evaluate.

Prismatic was a personalized news aggregator that used machine learning to surface articles matching your interests. It was popular in the data science community partly because it surfaced exactly this kind of niche technical tutorial that didn't surface in general news feeds. The platform shut down in 2015.

## Key points

- 2014 onboarding gap: Scikit-Learn ecosystem had no consolidated getting-started resource equivalent to today's tutorials.
- Core stack: Pandas for data loading, NumPy for arrays, Scikit-Learn for model fitting and evaluation.
- Prismatic as a technical news aggregator: surfaced niche tutorials before algorithm-driven feeds dominated.
- The how to get started question was harder in 2014 — [fast.ai](/notes/fastai/), Coursera's Python ML course, and Kaggle Learn all came later.
- Reflects the self-taught ecosystem that the first cohort of data science bootcamps also served.
