## Summary

This Data Science Central compilation serves as a curriculum map: 20 short tutorials that collectively cover the technical breadth expected of a working data scientist in 2014. The framing (should read and practice) is deliberate — these are hands-on exercises, not passive reading, with code examples in Python and R that readers can run and modify.

The range reflects what data science meant then: heavy overlap with statistics (probability theory, regression, Bayesian inference), growing emphasis on machine learning (decision trees, clustering, neural networks), and a practical floor of SQL and data manipulation proficiency. The list also includes domain topics like time series analysis, natural language processing basics, and data visualization — the full width of the job.

In 2014, most data scientists were self-taught or came from adjacent fields (statistics, physics, engineering), so curated reading lists like this one served as informal curricula. The data science bootcamp ecosystem was just emerging (Zipfian Academy, Galvanize, General Assembly), and these community lists were often the alternative.

## Key points

- Covers regression analysis, Bayesian statistics, clustering, decision trees, time series, and NLP basics — a snapshot of the full 2014 data science SKILL set.
- Code-based learning in Python and R: the expectation that practitioners can implement what they read, not just describe it.
- SQL proficiency appears as a given — data access is prerequisite to analysis, not a specialization.
- Data visualization included: the argument that communicating findings matters as much as producing them.
- Reflects the self-teaching culture of early data science: community knowledge aggregation filling the gap before formal bootcamps and university programs.
