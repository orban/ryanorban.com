## Summary

Published by Robbie Allen on the Unsupervised Methods blog in 2017, this curated list brought together what the author considered the best freely available learning resources across machine learning, NLP, and Python — organized by topic so practitioners could find what they needed. Lists like this were extremely valuable in 2017 because the field was growing faster than formal curricula could track, and the best material was scattered across personal blogs, GitHub repos, and university course pages.

The collection covered the full practitioner stack of the era: Python fundamentals, NumPy and pandas for data manipulation, scikit-learn for classical ML, introductory deep learning with TensorFlow and Keras, and specialized NLP topics like word embeddings and sequence models. This was before [fast.ai](/notes/fastai/), Hugging Face, and Distill had become the dominant educational resources — the landscape was more fragmented. Curated lists served as indexes to a library without a library catalog.

As a historical artifact, the list captures the data science learning ecosystem at a specific inflection point: Word2Vec was still novel, BERT was two years away, Kaggle was the primary competition venue, and Jupyter notebooks were becoming the standard format for sharing analytical work. The tutorials it linked tended to favor practical implementation over theory — a reflection of the practitioner-first culture that scikit-learn and later [fast.ai](/notes/fastai/) formalized.

## Key points

- 150+ curated tutorials organized by domain: Python basics, data manipulation, classical ML, deep learning, NLP.
- A 2017 snapshot of the canonical practitioner learning stack: scikit-learn, TensorFlow, Keras, pandas, Word2Vec.
- Published before BERT, [fast.ai](/notes/fastai/), and Hugging Face became dominant — reflects a more fragmented educational landscape.
- Lists like this served as community-maintained indexes when no single platform dominated ML education.
- Historical reference for what learning ML meant in the mid-to-late 2010s.
