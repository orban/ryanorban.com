## Summary

The Block Research produced this comparative framework analyzing seven layer-1 blockchain platforms: Algorand, Avalanche, Binance Smart Chain, Cosmos, Ethereum (including Ethereum 2.0 roadmap), Polkadot, and Solana. Commissioned by Algorand, though The Block retained editorial control. The timing — September 2021, peak L1 competition — makes it a useful snapshot of how the field looked before Terra's collapse reshuffled the deck.

The framework evaluates platforms across three dimensions: technical design (consensus mechanism, smart contract model, TPS limits, finality), ecosystem data (developer activity, TVL, DApp count), and qualitative factors (key ecosystem members, VC backing, governance structure). This tripartite structure is more honest than pure TPS benchmarking, which dominated the 2021 L1 narrative — a chain's actual ecosystem traction matters more than theoretical throughput.

The consensus mechanism differences are real and consequential. Proof of Stake variants differ significantly: Algorand uses Pure PoS (no slashing, random committee selection), Cosmos uses Tendermint BFT (immediate finality, slashing for double-sign), Polkadot uses Nominated PoS (stakers nominate validators, shared security via parachains), Solana uses Proof of History + PoS for low-latency ordering. These aren't just marketing differences — they produce different security and decentralization tradeoffs.

## Key points

- Covers Algorand, Avalanche, BSC, Cosmos, Ethereum 2.0, Polkadot, Solana — the leading L1 field in 2021.
- Three-axis comparison: technical design + ecosystem data + qualitative factors — more complete than pure TPS rankings.
- Consensus mechanism diversity: Pure PoS, Tendermint BFT, Nominated PoS, Proof of History — each with real tradeoffs.
- Commissioned by Algorand but authored by The Block Research — important provenance to note for bias assessment.
- Historical artifact: predates Terra/LUNA collapse and FTX contagion that significantly reshuffled L1 rankings.
