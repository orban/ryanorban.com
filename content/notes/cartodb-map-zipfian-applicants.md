## Summary

Jon Dinu, a Zipfian Academy student, built this CartoDB map showing the geographic distribution of Zipfian Academy applicants worldwide. The visual made the point that the data science bootcamp was attracting interest globally, not just from the San Francisco Bay Area — a useful message for a program that was still establishing its reputation.

CartoDB (now CARTO) was in 2014 the leading platform for cloud-based geospatial visualization. It provided a PostGIS-backed database, a web map editor, and embeddable visualization — you could upload a CSV with lat/lon columns and have an interactive map in minutes. For data science students learning to tell stories with data, CartoDB was a quick way to create compelling geographic visualizations without writing D3.js from scratch.

The map itself is a form of social proof through visualization — showing the global reach of applicants makes Zipfian Academy look more legitimate and desirable. Students creating promotional data visualizations about the program they're attending is a recursive data science application that the program would have encouraged.

## Key points

- Built by Zipfian Academy student Jon Dinu — a demonstration of skills using the program's own data.
- CartoDB (now CARTO): cloud geospatial platform with PostGIS backend, popular in 2014 for quick interactive maps.
- Geographic applicant distribution as social proof — global interest signals legitimacy.
- CartoDB made geographic data visualization accessible without D3.js expertise.
- Reflects the culture of Zipfian Academy: students doing real data work, including on the program itself.
