## Summary

This Quora thread from 2013 aggregated large open data sources specifically filtered to datasets of 1 GB or larger — the threshold that separates can process on a laptop from "actually exercises distributed computing." The question and its answers were widely linked as a starting point for machine learning practitioners who needed real data to practice on.

The 2013 open dataset landscape was fragmented: UCI Machine Learning Repository had the curated research datasets; Amazon Web Services hosted several public datasets (Common Crawl, Wikipedia dumps); government portals (data.gov, UK Open Data) were emerging but not well-known; and individual repositories on university websites scattered around the web. Quora's community answers aggregated these scattered sources.

Key sources mentioned in threads like this: Common Crawl web crawl data, Wikipedia database dumps, US Census and American Community Survey, NYC taxi trip data (which became a major benchmark for data engineering tutorials), GDELT (global events database), and domain-specific sources in genomics, climate science, and finance. The thread predates Kaggle Datasets (launched 2016) and HuggingFace Datasets (2021) — both of which later became the primary discovery mechanisms.

## Key points

- UCI Machine Learning Repository: curated research datasets for classification and regression benchmarks — the standard since the 1980s.
- Common Crawl: multi-terabyte web crawl data, hosted on AWS — used for language model training and web-scale NLP research.
- Wikipedia dumps: structured text, link graphs, and revision history — excellent for NLP and graph algorithm practice.
- Government data portals: data.gov, NYC Open Data, UK Open Data — structured civic data for public policy and urban analytics.
- The fragmentation problem: no single discovery layer in 2013 — Kaggle, HuggingFace Datasets, and Google Dataset Search hadn't been built yet.
