## Summary

Gesticulate was a gesture-recognition interface project from 2012 — likely using webcam-based computer vision or depth sensor input to translate physical gestures into computer commands. The original tweet context (I've been touched) suggests a demo that was experientially compelling — the kind of natural user interface that feels magical on first contact.

The 2012 context: Microsoft Kinect (2010) had demonstrated that gesture-based and body-tracking interfaces were technically feasible at consumer price points and had been hacked extensively by the maker community. The OpenNI framework and OpenCV made it easier to build gesture recognition systems. Projects like Leap Motion (hardware announced 2012, shipping 2013) were generating excitement about fine-grained hand tracking specifically.

Natural user interfaces (NUI) were a significant research and product theme in 2012 — the post-mouse, post-keyboard input paradigm. Kinect for Windows SDK had launched in February 2012, opening gesture development to Windows developers. The question of the time: would gesture replace touch, or would touch (via iOS and Android) become the dominant NUI paradigm? The answer turned out to be touch and voice — gestural mid-air interaction remained niche outside gaming.

## Key points

- Gesticulate: gesture-based computer control — part of the 2012 natural user interface exploration wave
- Key enabling hardware: Microsoft Kinect (2010), Leap Motion (2012-2013), webcam-based CV approaches
- OpenNI and OpenCV made gesture recognition accessible to independent developers
- The NUI competition: touch (iOS/Android) and voice (Siri, 2011) won; mid-air gesture remained gaming-specific
- Connects to current gesture work: Apple Vision Pro (2024) uses hand tracking for its primary input
