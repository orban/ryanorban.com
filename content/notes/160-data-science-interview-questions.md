## Summary

Alexey Grigorev (who also wrote "Machine Learning Bookcamp") compiled this list of 160 data science interview questions across the domains that appear in data science hiring: statistics and probability, machine learning theory, SQL and data manipulation, Python coding, and ML system design.

The breadth of coverage reflects how wide data science interviews actually are — unlike pure software engineering interviews (algorithms + systems) or pure ML research interviews (theory + papers), data science interviews mix quantitative foundations (explain p-value, what is Bayesian inference), practical coding (write a SQL query for cohort retention), and conceptual ML (what's the bias-variance tradeoff, how does XGBoost handle missing values). This breadth makes preparation harder.

The question set serves as a diagnostic: going through the list reveals gaps in your knowledge across the different domains. For a strong software engineer transitioning to data science, the statistics and probability questions often reveal the largest gaps. For a statistician entering industry, the SQL and engineering questions are typically weaker. The 160-question format covers enough ground to expose these gaps without being so long it's unusable.

## Key points

- 160 questions across: statistics/probability, ML theory, SQL, Python, and ML system design.
- Useful diagnostic: identify which domain (stats, coding, ML theory) is the weakest in your preparation.
- Statistics and probability questions: central limit theorem, A/B testing, Bayesian vs. frequentist, p-value interpretation.
- ML theory: bias-variance tradeoff, regularization, gradient boosting, cross-validation, model evaluation.
