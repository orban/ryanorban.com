## Summary

Portable Python Projects by Mike Riley (Pragmatic Programmers) teaches home automation using a Raspberry Pi and Python scripts. The book targets hobbyists and tech enthusiasts who want to control smart home devices without relying on third-party services or cloud subscriptions — a recurring theme in the self-hosting and DIY hardware communities.

The projects cover common home automation scenarios: smart lighting, temperature monitoring, voice-controlled devices. Each project is self-contained and scoped to be completable within an hour, which is a good design decision for a hands-on learning book. No electronics expertise required — the focus is on Python scripting that interacts with available Raspberry Pi GPIO and connected peripherals.

The appeal here is local control: unlike smart home setups dependent on vendor clouds (Nest, Philips Hue, Amazon Echo), a Raspberry Pi-based setup runs entirely on your local network. It doesn't break when a vendor changes their API or shuts down a service. This aligns with the broader self-hosting philosophy applied to home hardware.

## Key points

- Self-contained projects completable in ~1 hour — good for iterative learning on weekends.
- No electronics expertise needed: Python scripts interact with GPIO and connected devices.
- Local control philosophy: all automation runs on Raspberry Pi without cloud dependencies.
- Topics include smart lighting, temperature monitoring, voice control, and similar home automation patterns.
- Part of the DIY home automation ecosystem alongside tools like Home Assistant and ESPHome.
