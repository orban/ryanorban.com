## Summary

DAIR.AI's [ML YouTube Courses](/notes/ml-youtube-courses/) repository is a curated index of high-quality machine learning courses available free on YouTube. Maintained as a community resource, it aggregates courses from universities and researchers that would otherwise be scattered across individual channel pages and hard to discover.

The catalog covers the full ML stack: introductory machine learning, deep learning, natural language processing, computer vision, reinforcement learning, and specialized topics like graph neural networks and diffusion models. Courses come from academic institutions (MIT, Stanford, Carnegie Mellon, University of Toronto) and individual researchers like Andrej Karpathy and Lex Fridman.

The value is indexing. Most of these courses are individually findable if you know to search for them, but having them in one place with descriptions makes curriculum planning much easier. For someone trying to build systematic ML knowledge, this is a structured starting point that saves hours of searching.

## Key points

- Curated index of free machine learning and deep learning courses on YouTube.
- Maintained by DAIR.AI (democratizing AI research).
- Covers ML fundamentals, NLP, computer vision, reinforcement learning, diffusion models.
- Sources include MIT, Stanford, CMU, Andrej Karpathy, Lex Fridman.
- Open-source repository — community contributes new courses.
- Pairs with Awesome Machine Learning as a resource discovery tool.
