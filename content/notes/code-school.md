## Summary

[Code School](/notes/code-school/) (founded 2011 by Gregg Pollack) was one of the first interactive programming education platforms — the learn by doing tagline described an approach where you wrote and ran code in the browser as part of each lesson, rather than watching videos and coding separately. By 2012 it had courses on Ruby, Ruby on Rails, Git, JavaScript, and [CoffeeScript](/notes/coffeescript/), with a design that emphasized game-like progression (points, badges, level-up animations).

The competitive landscape in 2012: Codecademy (launched 2011) was targeting total beginners with free courses; [Code School](/notes/code-school/) was targeting working developers who wanted to pick up adjacent skills quickly, and charged a subscription fee. Treehouse (also 2011) occupied similar ground with more video-heavy content. The three companies defined the first wave of interactive programming education.

Code School's interactive model — write code, get feedback, advance — anticipated what would become the standard for programming education. The alternative (watch a lecture, then separately practice) had a high dropout rate from the gap between explanation and application. In-browser execution closed that loop.

Pluralsight acquired Code School in 2015 for $36 million — absorbing it into their enterprise-focused learning platform, which gradually eroded what made Code School distinctive (tight, fun, opinionated curriculum) in favor of breadth.

## Key points

- In-browser code execution + immediate feedback was the [Code School](/notes/code-school/) innovation — reduces the gap between understanding and practice.
- Subscription model ($25/month) vs. Codecademy's free model — different market segments (upskilling developers vs. beginners).
- Game mechanics (points, badges, level progression) applied to technical education — reduced dropout by making progress visible.
- Pluralsight acquisition (2015, $36M) is the canonical example of how enterprise learning platforms absorb developer-focused tools and lose what made them work.
- The legacy: every modern programming education platform (Egghead, Frontend Masters, Execute Program) is influenced by the learn-by-doing model Code School helped popularize.
