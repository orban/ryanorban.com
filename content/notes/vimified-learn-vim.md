## Summary

Vimified is a structured learning platform for Vim — the modal text editor that has a notoriously steep initial learning curve but rewards mastery with high-speed text editing. The platform offers short, focused lessons targeting practical proficiency: navigation, visual mode, motions and operators, macros, and the fundamental edit-repeat pattern (`c{motion}`, `.`) that makes Vim so efficient for repetitive editing tasks.

The problem Vimified addresses: Vim's built-in tutorial (`vimtutor`) covers the mechanics but doesn't build habits or provide feedback on whether you're developing correct muscle memory. Most people who try Vim abandon it after a few frustrating days, not because they couldn't learn it but because the path from knows the commands to "faster than their previous editor" is unclear and feedback-poor. Structured lessons with immediate feedback compress this path.

Vim has retained relevance despite IDEs because it's available everywhere (any Unix system), is the default editor in many server and embedded contexts, and has a keybinding system adopted by many other tools (Neovim, Helix, VS Code with Vim extension, Obsidian's Vim mode, browser extensions like Vimium). Learning Vim motions is a transferable investment — the same muscle memory applies across environments. Vimified positions itself as the fastest path to that investment paying off.

## Key points

- Structured Vim lessons with detailed feedback — focuses on building proficiency, not comprehensive coverage.
- Addresses the gap between knows commands and actually faster with targeted, feedback-rich exercises.
- Vim motions are transferable: Neovim, VS Code Vim extension, Obsidian, Vimium, Helix all use them.
- The `{operator}{motion}` composition model (e.g., `dw`, `ci"`, `gqip`) is what makes Vim fast — that's what to internalize.
- One of several interactive Vim learning tools; others include Vim Adventures, OpenVim, and `vimtutor`.
- Modal editing investment pays compound returns — every hour saved daily across years of use.
