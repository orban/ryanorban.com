## Summary

A resource links page hosted on Cloudera's S3 bucket for their Hadoop developer training course — the collection of documentation, tutorial links, and reference materials distributed to students in Cloudera's developer certification program. Cloudera University offered the main commercial Hadoop training and certification pathway in 2013, alongside Hortonworks' training program.

The Cloudera Certified Developer for Apache Hadoop (CCDH) certification was the main professional credential for Hadoop developers in 2013. It covered MapReduce programming, HDFS operations, Hive and Pig data processing, and cluster troubleshooting. Cloudera's training materials were among the most polished because Cloudera employed many of the core Hadoop committers who could write authoritative documentation.

The S3-hosted resource page reflects Cloudera's early content distribution approach before they moved to a proper LMS. These kinds of resource pages were how training content was shared in 2013 — static HTML with links rather than the later learning management systems like Coursera or Databricks Academy.

## Key points

- Cloudera University was the primary commercial Hadoop training provider alongside Hortonworks
- CCDH (Cloudera Certified Developer for Apache Hadoop): the main developer credential circa 2013
- Course content: MapReduce Java API, HDFS operations, Hive, Pig, HBase basics
- Static S3 page — likely dead link now; Cloudera has since moved to Cloudera Data Platform and different training infrastructure
- Competitor: Hortonworks' HDPCD certification covered similar ground on the Ambari-managed stack
