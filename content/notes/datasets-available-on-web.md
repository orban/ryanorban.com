## Summary

The Data Wrangling Blog maintained this curated list of public datasets as a community resource for data scientists and machine learning practitioners who needed real data to work with. In 2013, finding good datasets required bookmarking scattered resources like this — there was no single discovery platform.

The list covered a broad range of domains: social network graphs (Stanford SNAP), text corpora (Reuters, 20 Newsgroups, IMDB reviews), financial data, genomics (1000 Genomes Project), geospatial data, and government statistics. The common thread: these were datasets large enough to be interesting but publicly accessible without institutional credentials.

Paired with the Quora thread on large public datasets, this list represents the 2013 state of data discovery: community-maintained blogposts and wiki pages were the primary mechanism. The awesome datasets GitHub repositories that emerged around 2014-2015 superseded these individual curated lists, and eventually purpose-built platforms (Kaggle Datasets, HuggingFace Datasets, Google Dataset Search) formalized the discovery layer.

## Key points

- Stanford SNAP: social and information network datasets — friendship graphs, citation networks, product co-purchase graphs — widely used for graph algorithm research.
- Text corpora: 20 Newsgroups for text classification, Reuters news corpus for NLP — both standard benchmarks that remain in use today.
- UCI ML Repository as the anchor: the go-to for clean, labeled, well-documented research datasets since the 1980s.
- Domain-specific repositories were scattered: genomics had NCBI, climate data had NOAA, financial data had exchanges — no cross-domain aggregation.
- Community curation was the solution in 2013: blogposts like this, along with Reddit's r/datasets and Quora answers, served as informal dataset registries.
