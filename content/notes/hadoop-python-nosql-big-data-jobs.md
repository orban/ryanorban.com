## Summary

This 2014 InfoWorld piece analyzed job posting data to identify the most in-demand technical skills for big data roles — a category that was just starting to crystallize around specific tool expectations. The top three: Hadoop, Python, and NoSQL databases (primarily MongoDB and Cassandra). This snapshot captures the technology bets companies were making at the height of the big data boom.

The Hadoop dominance in 2014 job postings reflects the MapReduce era: companies had adopted HDFS-based data lakes following publications from Yahoo, Facebook, and Google about petabyte-scale processing. Hive and Pig made Hadoop more accessible, and the Cloudera and Hortonworks distributions had professionalized the deployment story. In hindsight, this was near the peak of Hadoop's job-market dominance — Apache Spark was already gaining traction and would supplant MapReduce within a few years.

Python at #2 reflected the data science community's convergence on it as the scripting and analysis language — NumPy, Pandas, and scikit-learn were mature enough by 2014 to displace R for many tasks. NoSQL demand reflected the application-side story: schemaless databases enabling rapid iteration without DBA bottlenecks.

## Key points

- Hadoop peak: 2014 was near maximum demand for Hadoop engineers; Apache Spark's rise starting in 2014-2015 would shift this within three years.
- Python had won the data science language war by 2014 for practical work, though R remained dominant in academia and statistics departments.
- NoSQL demand was driven by web-scale application patterns, not analytics — MongoDB for documents, Cassandra for high-write distributed storage.
- Salary premium for big data skills in 2014 was real: data engineers and data scientists commanded 30-50% premiums over traditional software developer rates.
- The "big data" label began losing signal in this era — the term became so broad it described both HDFS clusters and Excel spreadsheets with many rows.
