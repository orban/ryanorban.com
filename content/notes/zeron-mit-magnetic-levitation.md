## Summary

ZeroN is a project from MIT Media Lab, specifically Jinha Lee's research, that uses electromagnetic levitation to hold a small metal ball suspended in mid-air above a physical surface. What makes it more than a party trick: the system can record the ball's position over time, then play that trajectory back — letting the physical object "remember" and re-enact movement sequences.

The interaction model is genuinely novel. A user can grab the levitating ball with their hand, move it through a path, and release it. The system memorizes the trajectory. Later, it autonomously moves the ball through that same path. This collapses the distinction between spatial input and spatial output — the same physical object is both the controller and the display. This connects to broader work in tangible interfaces and embodied interaction design, where information has physical form rather than just screen representation.

The levitation mechanism pairs electromagnets above and below the ball, using real-time sensing and feedback control to keep the ball stable against gravity while allowing controlled lateral movement. The control loop runs fast enough that the ball appears to float naturally. The project was exhibited at the ACM CHI conference and represents Jinha Lee's broader interest in interfaces that exist in "between" the digital and physical — he went on to co-found SpaceTop, a 3D desktop computing interface.

## Key points

- Uses real-time electromagnetic levitation with position sensing to keep a metal ball stable in free space.
- Records and plays back 3D movement trajectories — the ball can autonomously re-enact paths a user taught it.
- Part of MIT Media Lab's tangible interfaces tradition (Hiroshi Ishii's Tangible Media Group).
- Same researcher (Jinha Lee) later built SpaceTop, a see-through 3D desktop where you work inside the screen.
- Demonstrates a design principle: collapse the distinction between input device and output display into one physical object.
