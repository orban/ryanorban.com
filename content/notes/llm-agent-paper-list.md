## Summary

This GitHub repository by Zhiheng Xi et al. is the companion paper list for their 86-page survey "The Rise and Potential of Large Language Model Based Agents." It catalogs research across all components of LLM-based AI agent systems — a structured bibliography for anyone wanting to understand the state of agent research at the pivotal moment in late 2023 when AutoGPT, BabyAGI, and early agent frameworks had demonstrated the concept but rigorous frameworks for thinking about agents were still being established.

The list is organized around the functional components that make up an agent: **planning** (task decomposition, chain-of-thought, ReAct, tree-of-thought); **memory** (short-term working memory, long-term storage via vector database, hybrid approaches); **tool use** (API calling, function calling, code execution); and **action** (text generation, physical world interaction, code execution). This decomposition became the standard framework for thinking about agent architecture.

The breadth is the value: 100+ papers across research groups worldwide, covering everything from single-agent planning to multi-agent coordination, grounding in environments, and safety considerations. For anyone entering the field in 2023, this was the map of the territory.

## Key points

- Companion bibliography to the "Rise and Potential of LLM Agents" survey (arxiv 2309.07864).
- Organized by agent component: planning, memory, tool use, action.
- 100+ papers across all major agent research directions as of September 2023.
- Planning coverage: chain-of-thought, ReAct, tree-of-thought, task decomposition.
- Memory coverage: short-term context, long-term vector database, [episodic memory](/notes/episodic-memory/).
- The most comprehensive LLM agent paper catalog from the early agent era.
