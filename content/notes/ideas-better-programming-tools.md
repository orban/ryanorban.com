## Summary

Emil Prog Viz is a personal site exploring ideas for making programming tools more comprehensible — drawing in the tradition of Bret Victor's work on learnable programming and observable computation. The core thesis: programs are fundamentally invisible as they execute, and better tools would make the behavior of running code as visible as the code itself.

The ideas range from better debuggers that show data flow visually rather than just state snapshots, to programming environments where you can scrub through execution history, to tools that help programmers understand what their code is actually doing rather than what they think it's doing. This connects to Dynamicland, Hazel, Observablehq, and other projects that push toward more transparent programming environments.

The underlying tension: most programming tools are optimized for experienced programmers who have internalized the execution model. Tools for learning and understanding are underinvested relative to tools for productivity. Emil's work explores the former category.

## Key points

- Programming tools that make execution visible — not just code text, but running behavior.
- In the tradition of Bret Victor's learnable programming work.
- Explores debuggers, execution visualization, and data flow transparency.
- Programming environments where you can scrub through execution history.
- Connects to projects like Dynamicland, Hazel, Observable, and Replit.
- Addresses the underinvestment in tools that build understanding vs. tools for productivity.
