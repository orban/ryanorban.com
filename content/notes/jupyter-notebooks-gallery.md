## Summary

notebook.community (formerly nbviewer-adjacent) is a gallery of interesting publicly shared Jupyter notebooks — a discovery interface for finding high-quality notebooks covering machine learning, data analysis, scientific computing, and data visualization. The site describes itself as "a gallery of the most interesting jupyter notebooks online."

Jupyter notebooks are a dominant format for exploratory data science and scientific computing: they combine executable code, rich output (plots, tables), and explanatory text in a single document. The challenge is discoverability — GitHub hosts millions of notebooks but has no quality filter. Gallery sites solve this by curating a subset worth looking at.

Notebooks make excellent learning artifacts because they show both the code and its output together, capturing not just what to write but what it produces. Worked examples in notebook format are often more useful than documentation for understanding how to apply a library or technique to a real problem.

## Key points

- Jupyter notebooks are the de facto standard for exploratory data science — the gallery addresses the discoverability problem within this ecosystem.
- High-quality notebooks combine explanation, code, and output — closer to executable essays than raw scripts.
- Good source for finding worked examples of specific techniques: how someone actually used SHAP for model explanation, how to structure a time series analysis, etc.
- The notebook format has limitations for production code: not version control friendly (JSON format makes diffs hard), execution order matters and can create state bugs.
- Alternative galleries: Kaggle notebooks (focused on competitions), Observable (JavaScript notebooks), Deepnote's community section.
