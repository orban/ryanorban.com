## Summary

Created by Stephanie Yee and Tony Chu at R2D3, this interactive piece is a landmark in using scrollytelling to explain machine learning. It walks through how a decision tree classifies data — specifically distinguishing NYC apartments from SF apartments — by animating each split as the user scrolls. You watch the algorithm divide the feature space in real time, building the tree node by node.

What makes it exceptional isn't the algorithm choice (decision trees are well understood) but the pedagogical commitment to showing rather than telling. Most ML education at the time was equation-heavy; this stripped the math entirely and focused on the geometric intuition — that classification is fundamentally about drawing boundaries in a feature space. The data point falls on one side of a threshold, then the next, then the next.

The piece was significant beyond its immediate audience. It popularized scrollytelling as a format for technical education and influenced a wave of interactive data journalism and ML explainers. 3Blue1Brown's neural network animations and later tools like GAN Lab and TensorFlow Playground share the same pedagogical philosophy: build intuition through directed interaction, not passive reading.

## Key points

- Uses real NYC vs. SF housing data to explain decision tree splits — concrete, not toy.
- Animates the feature space partition step by step — makes the algorithm's logic visible.
- No equations: the entire explanation runs on visual intuition.
- Pioneered scrollytelling for ML education — influenced data journalism and technical communication broadly.
- Part 1 of a series (Part 2 covers bias-variance tradeoff).
- Stephanie Yee and Tony Chu at R2D3 — one of the most-cited examples of ML visualization done right.
