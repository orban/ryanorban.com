## Summary

This macOS keyboard shortcuts reference by Jamie (jamieonkeys.dev) is a developer-focused compilation covering system-wide shortcuts, terminal, browser, and editor workflows. The value is breadth over any individual shortcut — most developers know the common shortcuts but are unaware of the less-obvious ones that can significantly reduce mouse usage. The post reflects a philosophy that keyboard-driven workflows compound over time: learning a shortcut that saves 2 seconds, used 50 times a day, saves 100 seconds daily, which is roughly 6 hours a year per shortcut.

Key areas typically covered in references like this: Mission Control and window management (Cmd+Tab for apps, Cmd+` for windows within an app, Ctrl+Arrow for spaces), text editing universals that work across most macOS apps (Opt+Arrow for word navigation, Cmd+Arrow for line navigation, the [[Emacs]]-style [[Ctrl]]+A/E/K for beginning/end/kill-to-end-of-line), [[Terminal]] shortcuts (history navigation, reverse search with Ctrl+R, readline bindings), and browser shortcuts ([[Cmd+L]] for address bar, Cmd+T/W for tab management).

The developer-specific layer includes: [[VS Code]] or editor shortcuts for multi-cursor, go-to-definition, and command palette; [[Alfred]]/[[Raycast]] launcher shortcuts that replace [[Spotlight]]; terminal multiplexer ([[tmux]]) bindings if relevant; and system shortcuts like [[Cmd+Space]] for Spotlight, [[Cmd+Shift+4]] for screenshots, and [[Quick Look]] (Space in [[Finder]]). The macOS text shortcuts in particular — Emacs-style bindings that work in every native text field — are the highest-leverage because they apply everywhere rather than just in one application.

## Key points

- [[Emacs]]-style bindings work system-wide in macOS: Ctrl+A (beginning of line), Ctrl+E (end), Ctrl+K (kill to end), Ctrl+D (delete char) — available in every native text input.
- [[Mission Control]]: Ctrl+Up/Down for overview, Ctrl+Left/Right to switch spaces, Ctrl+Number for specific spaces.
- [[Cmd+`]] (backtick): cycle between windows of the current app — underused but eliminates most cmd+tab ambiguity.
- Raycast/Alfred: launcher shortcuts are multipliers — one trigger to reach any app, file, clipboard item, or script.
- Screenshot: Cmd+Shift+3 (full), Cmd+Shift+4 (selection), Cmd+Shift+4+Space (window), Cmd+Shift+5 (toolbar).
- Terminal reverse search: Ctrl+R — searches command history interactively; highest ROI terminal shortcut after basic navigation.
