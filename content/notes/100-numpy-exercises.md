## Summary

Nicolas Rougier's 100 exercises for NumPy range from beginner to advanced, covering the core operations that make NumPy indispensable for scientific computing in Python. The collection originated at LORIA (Laboratoire Lorrain de Recherche en Informatique et ses Applications) and became a widely-shared resource in the Python data science community.

The exercises build intuition for array operations, broadcasting, indexing, and vectorization — the patterns that distinguish idiomatic NumPy code from naive Python loops. Working through them is one of the most effective ways to internalize NumPy's mental model: think in shapes, not loops.

## Key points

- Covers 100 problems from basic array creation to advanced operations like stride tricks and fancy indexing
- Forces pattern recognition: many problems have elegant one-liner solutions that require knowing NumPy's full API
- Good complement to tutorials — exercises expose gaps that reading documentation alone won't reveal
- The vectorization mindset developed here transfers directly to pandas, scikit-learn, and PyTorch
- Hosted on GitHub so contributors can add solutions and new exercises over time
