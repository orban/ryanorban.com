## Summary

Codecademy's Ruby track offered browser-based interactive exercises for learning Ruby from scratch — no installation, no setup, just a code editor and a test runner in the browser. The curriculum covered variables, control flow, methods, classes, modules, iterators, and blocks — the core of Ruby syntax — through immediate feedback on each exercise.

Codecademy was one of the main routes into programming in 2013-2014 for people who weren't computer science students. The interactive format lowered the barrier significantly: you could start writing and running code within 30 seconds of visiting the site, which compared favorably to setting up a local environment.

## Key points

- Browser-based: no install required — write Ruby in an editor pane, see output and test results immediately
- Curriculum builds from variables and methods through OOP and Ruby blocks/iterators — the constructs that make Ruby distinctive
- Ruby blocks and the `yield` pattern are well-covered — the feature most coming from Python or Java need the most help with
- Typically paired with _why's Poignant Guide to Ruby for learners who wanted both interactive practice and narrative explanation
- Codecademy later added Python, JavaScript, SQL and other tracks, becoming a primary resource for self-taught programmers
