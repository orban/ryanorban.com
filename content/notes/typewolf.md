## Summary

[Typewolf](/notes/typewolf/) is a typography reference site run by Jeremiah Shoaf that curates exceptional real-world examples of web typography. The Site of the Day archive is the most useful section: each featured site is tagged with every typeface used, links to the font source, and a screenshot showing the typography in context. For designers choosing fonts, seeing how a typeface renders on an actual production site is far more informative than a type specimen page.

The curation is opinionated and consistent — [Typewolf](/notes/typewolf/) features sites that use typography confidently, with clear hierarchy and considered pairings. This makes the archive useful both as a visual inspiration source and as a typeface discovery mechanism. If you're looking for a serif with a specific character (geometric, humanist, transitional), browsing [Typewolf](/notes/typewolf/)'s archive by font name or category surfaces real examples rather than abstract classifications.

[Typewolf](/notes/typewolf/) also publishes guides on popular typefaces — what fonts pair well with X, which typefaces look like Y — and maintains a popular fonts trending list that tracks which typefaces are appearing most on well-designed sites. This has made it a go-to resource for both professional designers and developers who want to make informed font choices without deep typography training. The Site of the Day format creates a daily touchpoint for design awareness.

## Key points

- [Typewolf](/notes/typewolf/) archives real-world typography examples with fonts identified — see typefaces in context, not just specimen pages
- Each featured site lists all typefaces used with links to sources (Google Fonts, Adobe Fonts, foundry purchases)
- Curated by Jeremiah Shoaf: consistent quality bar — sites with confident, considered typographic choices
- Trending fonts list: which typefaces appear most on design-forward sites — useful signal for what's current
- Font pairing guides: concrete recommendations for combining serif + sans, display + body, etc.
- Related: Fonts In Use (similar concept, broader scope), Fonts Ninja browser extension, Google Fonts for open-source typefaces
