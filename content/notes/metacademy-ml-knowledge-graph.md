## Summary

Metacademy is a knowledge graph for machine learning and probabilistic artificial intelligence. Each concept is a node with explicitly listed prerequisites — you can navigate to any topic (say, Variational Inference) and see the minimum prerequisite knowledge tree you need to understand it first. The site then surfaces specific resources (papers, textbook chapters, lectures) for learning each node.

This was a genuinely novel approach to curriculum design in 2013: instead of a linear course or a reading list, it presents the prerequisite structure as a directed graph. You start where you are, trace the path to where you want to be, and learn concepts in dependency order. It's particularly useful for the Bayesian machine learning ecosystem, which has deep mathematical prerequisites that are easy to stumble over without a map.

Roger Grosse and David Duvenaud built Metacademy, both then at University of Toronto in the Geoffrey Hinton group. The Bayesian ML roadmap is a pre-curated path through the graph for someone wanting to learn that specific area from scratch.

## Key points

- Dependency graph of ML/probability concepts — each node has explicit prerequisite links and suggested resources.
- Navigate to any advanced topic and get the full prerequisite tree to learn it.
- Particularly strong coverage of Bayesian machine learning, probabilistic graphical models, and neural networks.
- Built by Roger Grosse and David Duvenaud from University of Toronto.
- The site embeds the insight that learning order matters: some concepts require other concepts; ignoring prerequisites leads to confusion.
- Alternative to course-based learning: structure your self-study by the concept dependency graph rather than a professor's syllabus.
