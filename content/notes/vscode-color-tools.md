## Summary

Three VS Code theme-related saves from the same session (April 15, 2021) reflect a theme customization research exercise:

**VSCodeThemes** (vscodethemes.com) is a visual gallery that lets you preview VS Code themes without installing them — you see code samples rendered in each theme's colors before committing to an install. This solves the friction of the normal workflow (install, preview, uninstall if bad, repeat).

**VSColors** (vscolors.com) is a similar tool oriented toward browsing and comparing the color palettes of popular VS Code themes.

**Nord** (nordtheme.com) is a specific theme/color palette — a cool-toned, arctic-inspired palette of muted blues and grays. Nord has been ported to many applications beyond VS Code: terminal emulators (iTerm2, Alacritty), Vim/Neovim, JetBrains IDEs, macOS, and more, making it a coherent visual identity that can span the full development environment.

## Key points

- VSCodeThemes and VSColors: preview galleries for finding VS Code themes without install-try-uninstall cycles.
- Nord theme: arctic-inspired cool blue/gray palette with wide ecosystem support beyond VS Code.
- Nord's multi-app portability makes it a popular choice for developers who want visual consistency across tools.
- One Dark Pro, Dracula, Gruvbox, and Nord are the most commonly recommended VS Code dark themes.
