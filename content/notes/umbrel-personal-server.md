## Summary

Umbrel is an operating system for running a personal home server, specifically designed to make self-hosting accessible to non-technical users. The headline use cases are Bitcoin full nodes and Lightning Network nodes — Umbrel became popular in the Bitcoin community as the easiest way to run your own node on a Raspberry Pi. But the platform grew to include a broad app store: Nextcloud (self-hosted Google Drive alternative), Bitwarden (self-hosted password manager), Home Assistant, Jellyfin, and dozens more.

The product philosophy is "sovereignty" — your data and infrastructure running on hardware you own rather than on third-party cloud services. The Bitcoin community's philosophical alignment with self-hosting (run your own node, verify your own transactions) made Umbrel a natural fit as a general self-hosting platform. The one-click app installs abstract away Docker container management and port configuration that would otherwise require significant Linux knowledge.

The broader self-hosting movement in 2022 was growing as awareness of data privacy issues increased and cloud service reliability concerns (Twitter changing APIs, services shutting down) pushed more users toward local-first software. Umbrel sits at the consumer end of this spectrum — more accessible than raw Docker Compose setups, less powerful than Proxmox home lab configurations.

## Key points

- Umbrel: personal server OS with app store — Bitcoin node, Lightning, Nextcloud, Bitwarden, Home Assistant with one-click installs
- Raspberry Pi or x86 home server — cheap hardware, full sovereignty over data
- Docker-based app management abstracted behind a friendly UI — no terminal knowledge required
- Bitcoin/Lightning community origin: run your own full node, verify transactions without trusting a third party
- App store model mirrors how mobile OSes made software distribution easy — same pattern applied to self-hosting
- Related: Start9 (similar product, more privacy-focused), CasaOS, YunoHost
