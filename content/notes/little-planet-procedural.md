## Summary

This project by Alan Luo was created as a midterm submission for a procedural generation course and demonstrates algorithmic terrain and world generation in the style of a little planet — a compact, spherical or semi-spherical world generated from code rather than hand-authored. The original URL is no longer accessible, but the project structure (`alanluo.com/procgen/midterm.html`) situates it firmly in the creative coding tradition of browser-based generative environments.

"Little planet" aesthetics in computer graphics typically combine two ideas. One is the stereographic projection technique familiar from photography — projecting a 360-degree panorama into a sphere-like distortion that makes landscapes look like tiny globes. The other, more relevant to procedural generation, is building a small self-contained world algorithmically: using Perlin noise or simplex noise to generate terrain height maps, adding biomes by layering noise octaves, placing vegetation or structures using rule-based placement. The result is a world that looks hand-crafted but is entirely synthesized from mathematical functions.

Procedural generation as a course subject grew in prominence during the 2010s, partly due to games like Minecraft, No Man's Sky, and Spelunky popularizing the aesthetic and partly because browser-based tools (three.js, p5.js) made real-time 3D generative work accessible without native compilation. Student midterm projects in this space typically demonstrated competence with noise functions, spatial data structures, and rendering — the building blocks of any procedural world.
