## Summary

Roger Grosse's Bayesian machine learning roadmap on Metacademy is a curated learning path through the full stack of Bayesian inference techniques used in modern ML. Unlike a textbook or course, it structures the curriculum as a dependency graph — each topic lists what you need to know first and links to the best resources for learning it.

The roadmap covers the conceptual foundations (probability theory, Bayes' theorem, conjugate priors), moves through probabilistic graphical models (Bayesian networks, Markov random fields), then into approximate inference methods (MCMC, variational inference, expectation propagation), and finally to nonparametric methods (Gaussian processes, Dirichlet processes). Each node links to textbook sections from Bishop's PRML or Murphy's ML: A Probabilistic Perspective, plus lecture notes and papers.

This is the map that explains why Bayesian ML feels so hard to enter without guidance: the prerequisite structure is deep and branching. Grosse and Duvenaud made the structure explicit so you could navigate it systematically.

## Key points

- Structured dependency path through Bayesian machine learning: probability foundations → graphical models → approximate inference → nonparametric methods.
- Each node has explicit prerequisites — the graph shows what must come before what.
- Resources for each topic link to PRML (Bishop), Murphy's *ML: A Probabilistic Perspective*, and primary papers.
- Key topics: conjugate priors, Bayesian networks, Markov random fields, MCMC, variational inference, Gaussian processes, Dirichlet process.
- Created by Roger Grosse (then at U of T, now at U of Toronto CS faculty).
- The roadmap format is itself an interesting design: making the prerequisite DAG navigable rather than hiding it.
