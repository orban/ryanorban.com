## Summary

Pipeline Data Engineering Academy curates free resources for learning data engineering — covering the practical toolchain that data engineers use daily. The list addresses the gap between "I want to become a data engineer" and knowing which skills to prioritize and where to learn them without paying for expensive bootcamps.

The core SKILL areas covered: SQL fundamentals and window functions (the single most critical data engineering skill), Python for data pipelines, distributed processing with Apache Spark, workflow orchestration with Apache Airflow, SQL-based transformation with dbt, and cloud data warehouse basics (BigQuery, Snowflake, Redshift). Each area has free course or documentation links.

The data engineering career transition is common for analysts who want to work more on infrastructure, and for software engineers who want to work with data. The field's toolchain was rapidly standardizing around 2022: the [modern data stack](/notes/modern-data-stack/) (Fivetran → Snowflake/BigQuery → dbt → Looker) had clear skill requirements that this type of curation helps aspiring data engineers understand and prioritize.

## Key points

- SQL first: window functions, CTEs, query optimization — essential before anything else.
- dbt (data build tool): SQL-based transformation with testing, documentation, and lineage tracking.
- Apache Spark: distributed data processing for volumes beyond single-machine scale.
- Apache Airflow: workflow orchestration for scheduling and monitoring data pipelines.
- Cloud warehouses: BigQuery, Snowflake, Redshift — free tiers available for practice.
