## Summary

Christophe Viau's D3.js examples gallery was one of the primary community resources for learning D3.js through examples in 2013. The official D3.js documentation by Mike Bostock was comprehensive but not always beginner-friendly, and the canonical examples (on bl.ocks.org) weren't organized for browsing. Viau's gallery catalogued hundreds of D3 examples by type, making it easy to find how do I make a chord diagram or "what does a force-directed layout look like."

D3.js had been released in 2011 by Mike Bostock (then at the New York Times) and quickly became the standard tool for bespoke data visualization on the web. Its approach was different from chart libraries: D3 bound data to DOM elements and let you define the visual encoding explicitly, giving complete control at the cost of a steep learning curve. Examples were the primary teaching medium.

Saved during the Zipfian Academy period when data visualization was part of the curriculum — D3 was the tool for interactive web-based visualization, matplotlib for static analysis charts.

## Key points

- Christophe Viau's gallery organized hundreds of D3.js examples by visualization type — the missing index for the community.
- D3.js (Data-Driven Documents): Mike Bostock's library binding data to DOM elements; full control, steep learning curve.
- D3 examples were the primary teaching medium because the library's power was hard to convey without seeing it in action.
- New York Times graphics desk (where Bostock worked) was producing some of the most influential interactive journalism visualizations using D3.
- matplotlib vs. D3.js split the data science world: analysis/static work in Python, interactive/web work in JavaScript D3.
