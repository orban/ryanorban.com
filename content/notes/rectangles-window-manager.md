## Summary

Rectangle is a free, open-source macOS window management application that lets you move and resize windows using keyboard shortcuts. It's the successor to the popular (but unmaintained) Spectacle app, and has become the default recommendation for window snapping on macOS without paying for Magnet (the paid App Store equivalent). The core functionality: keyboard shortcuts to move windows to left half, right half, top/bottom thirds, corners, maximized, and other common positions.

The value proposition is straightforward: macOS doesn't have built-in window snapping (unlike Windows' Aero Snap), and using the mouse to precisely position windows is slow. With Rectangle, Ctrl+Opt+Left/Right snaps to halves, Ctrl+Opt+Return maximizes, and various corner combinations handle quadrant layouts. For developers working with multiple windows — terminal, editor, browser, documentation — this is a daily-use utility with immediate ROI.

Rectangle Pro (paid version) adds more advanced features: custom window layouts, window cycling, multi-display profiles, and almost maximize (slightly inset from full screen). The free version covers the majority of everyday needs. Open-source at GitHub under the MIT license.

## Key points

- Free, open-source macOS window manager — the popular Spectacle successor.
- Keyboard shortcut-driven: snap to halves, thirds, corners, maximize without mouse dragging.
- Fills the gap macOS left by not including Windows-style window snapping natively.
- Rectangle Pro adds custom layouts and multi-display profiles; free version handles daily needs.
- No accessibility permissions exploit — uses macOS accessibility APIs correctly.
- Alternative: Magnet (paid, App Store), Moom (paid), yabai (for tiling window management).
