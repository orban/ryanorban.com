## Summary

Brad Frost built This Is Responsive as a reference resource for web designers and developers learning [responsive web design](/notes/responsive-web-design/) — a curated collection of patterns, resources, and real-world examples organized by component type (navigation, tables, images, forms, data). It launched at the moment Ethan Marcotte's 2010 article and 2011 book had established [responsive web design](/notes/responsive-web-design/) as the industry direction, but practitioners were still figuring out how to actually implement it at the component level.

The core concept of [responsive web design](/notes/responsive-web-design/) (RWD): fluid grids, flexible images, and CSS media queries working together so a single HTML document renders appropriately across screen sizes — from phones to tablets to desktop monitors. Rather than separate mobile sites (the dominant pattern before RWD), the same codebase adapts. Ethan Marcotte coined the term and A List Apart published the original article in 2010; by 2012 the industry had broadly accepted the concept but was still developing the practical patterns.

Brad Frost was doing this work alongside his broader contribution to front-end methodology — he later developed Atomic Design (2013), a systematic approach to building design systems from the smallest components up. This Is Responsive was part of the same intellectual project: moving web design from page-based thinking to component-based, pattern-based thinking. Bootstrap (Twitter, 2011) was the most popular implementation of responsive grids at the time, and Foundation (ZURB) was the main alternative.

## Key points

- Ethan Marcotte's [responsive web design](/notes/responsive-web-design/) (2010): fluid grids + flexible images + media queries = single codebase for all screen sizes
- This Is Responsive: pattern library organized by component — navigation patterns, responsive tables, image handling, forms across breakpoints
- Brad Frost later developed Atomic Design — the component-library methodology that underlies modern design systems
- Bootstrap (2011, Twitter): the dominant responsive grid framework — made 12-column fluid grids accessible to developers who didn't want to build from scratch
- Mobile-first design principle: design for the smallest screen first, then add complexity at larger breakpoints — Luke Wroblewski's influential approach
