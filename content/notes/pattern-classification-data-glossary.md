## Summary

Sebastian Raschka's data glossary lives inside his pattern_classification GitHub repository — a larger collection of machine learning notebooks and reference material. The glossary itself is a Markdown document defining terms across statistics, machine learning, pattern recognition, and data science with brief, precise definitions and cross-references.

In 2014, the field suffered from significant vocabulary inconsistency: the same concept might be called features in ML, predictors or covariates in statistics, and attributes in databases. Raschka's glossary attempted to bridge these dialects — defining terms in a way that acknowledged their varied usage while providing a canonical reference. This was particularly useful for people crossing from one tradition (statistics, software engineering, domain science) into data science.

Sebastian Raschka went on to write Python Machine Learning (2015), which became one of the most-used practical ML textbooks, and later joined academia as a professor. The pattern_classification repository was his public notebook during his own learning and research process — a model of learning in public that influenced how many ML practitioners started sharing their work on GitHub.

## Key points

- Covers bias, variance, overfitting, underfitting, cross-validation, regularization, feature engineering, dimensionality reduction — the core ML vocabulary.
- Explicitly bridges statistics ↔ ML terminology: same concept, different names across disciplines (e.g., MLE vs. ordinary least squares, precision/recall vs. sensitivity/specificity).
- Raschka's pattern_classification repo also contains IPython notebooks for algorithms from scratch — the glossary is the vocabulary layer on top of the implementations.
- Community-maintained on GitHub, which allowed corrections and additions — GitHub as a collaborative reference tool, not just a code host.
- Historical context: precedes the explosion of ML courses (Coursera's ML specialization, fast.ai) that later built shared vocabulary at much larger scale.
