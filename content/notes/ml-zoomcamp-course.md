## Summary

ML Zoomcamp by Alexey Grigorev is a free, cohort-based machine learning course that runs as a structured curriculum with weekly sessions, homework, and a final project. Grigorev is the author of Machine Learning Bookcamp (Manning) and runs DataTalks.Club, a community for data professionals. The course is practical-first: less mathematical theory, more "how do I build and deploy a working ML system."

The curriculum covers: regression models (linear, decision trees), classification (logistic regression, random forests, XGBoost), deep learning with TensorFlow/Keras, model deployment (as REST APIs with Flask, containerized with Docker), and MLOps fundamentals (serving, monitoring). The GitHub repository contains all notebooks, datasets, and homework assignments.

The zoomcamp format (originally developed by Alexey Grigorev with [Data Engineering Zoomcamp](/notes/data-engineering-zoomcamp/) and ML Zoomcamp) became a successful free education model in the ML community. Cohorts run a few times per year with live sessions; the material is available for self-study between cohorts. The community on Slack and the homework review process provide accountability that pure self-study lacks.

This is aimed at software engineers transitioning into ML or data scientists wanting more deployment skills — not research scientists. The deployment and MLOps sections are the differentiator from most intro ML courses that stop at model training.

## Key points

- Alexey Grigorev: author of Machine Learning Bookcamp, founder of DataTalks.Club
- Practical curriculum: regression → classification → deep learning → deployment → MLOps
- Model deployment with Flask + Docker — real deployment, not just notebook training
- Free cohort model: live sessions, homework, peer review, community — structured accountability
- Differentiator vs. standard intro courses: deployment and production model serving are core topics, not afterthoughts
