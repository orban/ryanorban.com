## Summary

This Bitbucket repository by Hernán Rojas is a series of IPython notebooks for learning Pandas from scratch. In 2014, Pandas documentation was improving but still sparse on worked examples, and the library's API was significantly different from what most people coming from R or Excel were used to. Tutorial series like this filled the gap.

Pandas is a Python library for tabular data manipulation built on NumPy. Its central abstractions — `DataFrame` and `Series` — map naturally to spreadsheet-style data, but the indexing system, `groupby` mechanics, and method chaining patterns take genuine effort to internalize. Notebook-format tutorials made it easier because you could run each cell and immediately see the output.

The notebook format itself was still relatively new in 2014 — IPython notebooks became Jupyter notebooks officially in 2015. This tutorial represents the genre of community-generated learning materials that bootstrapped the entire Python data science ecosystem before formal courses and textbooks existed.

## Key points

- IPython notebook series covering Pandas fundamentals: loading, indexing, groupby, merge, time series.
- Community-generated Pandas education from an era when official docs were sparse.
- Pandas `groupby` in particular was (and is) one of the most powerful but confusing parts of the API.
- Hosted on Bitbucket — reflects that era's development tool landscape, before GitHub became near-universal.
- Part of the self-taught ecosystem that preceded formal data science education programs.
