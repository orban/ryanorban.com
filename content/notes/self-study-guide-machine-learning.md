## Summary

Jason Brownlee's [Machine Learning Mastery](/notes/machine-learning-mastery/) site published this structured self-study guide for practitioners wanting to learn machine learning without a formal academic path. Brownlee's approach was deliberately top-down: don't start with theory and work toward applications, start with working code and a running model, then fill in theory as needed.

The staged curriculum moves from establishing a foundation (Python or R, statistics basics, linear algebra), through core ML algorithms (linear regression, decision trees, SVMs), to model evaluation practices (cross-validation, performance metrics, baseline comparison), and finally to the practice of applying ML to real datasets with the full workflow: data loading, cleaning, feature engineering, model selection, and deployment.

Brownlee's philosophy — which became influential — is that "working on real problems is the fastest path to competence." The guide resists the temptation to work through textbooks linearly, instead advocating small projects as the unit of learning. Each algorithm gets implemented and run on real data before moving to the next one.

## Key points

- Top-down approach: start with working code and a model, then fill in the math. Opposite of academic textbook approach.
- Staged curriculum: Python/R basics → statistics → core algorithms → model evaluation → full workflows.
- Core algorithms prioritized: linear regression, logistic regression, decision trees, SVMs, k-NN, naive Bayes.
- Cross-validation and proper model evaluation treated as first-class skills, not afterthoughts.
- The project as unit of learning approach: implement each algorithm on a real dataset before moving on.
- Jason Brownlee went on to build Machine Learning Mastery into one of the highest-traffic ML educational sites.
