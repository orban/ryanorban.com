## Summary

Data in Practice is a technical blog by Daniel Baumgartel covering practical implementation of data science and machine learning concepts with working code. The blog sits in the practitioner-written tutorial space that was essential for self-education in 2014 — before MOOC platforms had comprehensive ML content and before the current era of YouTube explainers.

The topics span what was considered the modern data science stack: Python implementations of algorithms from scratch, distributed computing concepts (Hadoop, Spark), and applied machine learning projects. Writing implementations from scratch (rather than just calling library functions) is a pedagogical choice that forces understanding of how algorithms actually work — the difference between knowing that gradient descent optimizes a loss function and understanding the update rule.

Blogs like this played a role in 2014 that's been partially displaced by more organized learning platforms — but practitioner blogs often covered more advanced or niche topics faster than courses, because the author was writing about something they'd just figured out.

## Key points

- Code-first pedagogy: implementing algorithms from scratch in Python to force genuine understanding vs. black-box API usage.
- Covers distributed computing (Hadoop, Spark) alongside ML — reflecting the 2014 reality that data scientists often had to manage their own infrastructure.
- Practitioner blogs in 2014 were a primary knowledge transfer mechanism: faster than books, more detailed than Stack Overflow, more honest about tradeoffs than vendor docs.
- Category: learning resources for the self-teaching data scientist era.
