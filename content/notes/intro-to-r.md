## Summary

Alyssa Frazee — then a PhD student in biostatistics at Johns Hopkins — wrote this introduction to R aimed at people who were curious about what the language was actually for. The post explains R not as an alternative to Python but as a purpose-built environment for statistics: tight integration between data manipulation, modeling, and visualization, and a package ecosystem (CRAN) where every statistical method gets implemented in R first.

Frazee's perspective as a working biostatistician gives the introduction practical weight. She uses it daily for RNA-seq analysis, differential expression, and statistical modeling — contexts where Python's statistical depth was thinner in 2014 and R's bioinformatics packages (Bioconductor) had no equivalent.

## Key points

- R is a statistical computing environment, not just a scripting language — the base language has vectors, factors, and data frames as native types
- CRAN (Comprehensive R Archive Network) is R's package ecosystem — nearly every published statistical method has an R implementation, often from the method's authors
- ggplot2 (Hadley Wickham) is built on the grammar of graphics — declarative plots that compose better than matplotlib's imperative API
- Bioconductor adds a vast repository of bioinformatics tools built on R — no Python equivalent existed at this depth in 2014
- The interactive REPL encourages exploratory analysis: inspect data at each step, which fits the iterative nature of statistical work
