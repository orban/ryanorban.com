## Summary

[Reactive Resume](/notes/reactive-resume/) is a free and open-source resume builder built to make creating, updating, and sharing resumes as frictionless as possible. The interface focuses on a live-preview editor where you see the formatted resume as you type, and it supports multiple templates for different styles and industries.

The core value proposition over paid resume builders (like Resume.io or Zety) is that it's entirely free and your data isn't locked into a subscription. You can export to PDF at any time, and the code is on GitHub — self-hosting is possible if you want full control. The project is community-maintained under MIT license.

For a tool in a category (resume builders) dominated by dark-pattern-heavy SaaS that charges $30/month to download your own resume, an open-source alternative with a polished UI is a notable exception. It sits alongside tools like flowcv in the free-resume-builder space.

## Key points

- Free and open-source resume builder with live preview.
- Multiple resume templates; export to PDF.
- No subscription required to download your resume.
- Self-hostable — full control over data and hosting.
- MIT license; community-maintained on GitHub.
- Alternative to subscription-gated builders like Resume.io.
