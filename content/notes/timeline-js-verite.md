## Summary

Timeline JS (by Vérité) is an open-source JavaScript library for building interactive, embeddable timelines from simple data sources — primarily a Google Spreadsheet. The zero-code approach made it a hit with journalists, educators, and storytellers who wanted to present sequences of events without writing custom code.

The tool produces timelines that work across screen sizes with rich media support — images, video, tweets, Wikipedia articles, and other embeds per event. The Google Spreadsheet backend means the timeline can be updated without touching code or redeploying anything. This was a particularly powerful combination in 2012, when collaborative editing of a spreadsheet was far more accessible than managing a database or CMS.

Timeline JS was part of a wave of narrative data visualization tools — alongside Leaflet.js for maps and Datawrapper for charts — that targeted journalists and newsrooms specifically. The Knight Foundation and Northwestern journalism school (Vérité was a Knight Lab project) funded this category of tool explicitly to lower the barrier between data and publishable interactive stories.

## Key points

- Timeline JS drives timelines from a Google Spreadsheet — update the sheet, the timeline updates automatically
- Rich media per event: images, YouTube, Vimeo, Wikipedia, Twitter embeds
- Created by Knight Lab at Northwestern University — part of a portfolio of open-source journalism tools
- Responsive by default — timeline adapts to mobile vs. desktop
- Part of the 2012 computational journalism wave: Knight Lab, ProPublica, The Guardian data team
