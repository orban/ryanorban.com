## Summary

*Dive into Machine Learning* by hangtwenty was one of the most-starred beginner resources for machine learning in 2015, structured around Jupyter notebooks and scikit-learn rather than heavy textbooks. The philosophy: get your hands dirty with real data first, then go deep on theory when you have concrete questions to answer.

The guide works as a curation layer — it links to IPython Notebook examples, external tutorials, and canonical blog posts, then ties them together into a learning path. The emphasis on scikit-learn was prescient; it became the dominant library for classical ML in Python and remains so today.

What made this notable at the time was the emphasis on *doing* over *reading*. The ML education landscape of 2015 was dominated by heavy MOOCs (Andrew Ng's Coursera machine learning course being the canonical example) and dense textbooks. A short, notebook-driven guide aimed at getting a working pipeline running quickly filled a real gap for practitioners.

## Key points

- Built around Jupyter notebooks + scikit-learn — hands-on from the first page.
- Curates external resources rather than trying to explain everything from scratch.
- Contrasts with theory-first approaches like Andrew Ng's Coursera course.
- Reflects the 2015 data science bootcamp ethos: build intuition through doing, not reading proofs.
- Predecessor to resources like [fast.ai](/notes/fastai/), which made the hands-first philosophy more sophisticated.
