## Summary

_why the lucky stiff wrote this guide to Ruby as a combination programming tutorial and illustrated surrealist narrative — complete with cartoon foxes, non-sequitur digressions, and chunks of actual Ruby code. The result is unlike any other programming book: the code examples work, the explanations are correct, but the delivery is maximally strange. It was designed to make learning to program feel like discovery rather than rote procedure.

The guide became a Ruby community artifact. When _why deleted all his work and disappeared from the internet in 2009, the community scrambled to recover and preserve everything. The Poignant Guide survived and continued to be passed around as an example of what programming education could look like if the author cared more about the reader's experience than appearing authoritative.

## Key points

- Covers Ruby basics — variables, flow control, blocks, classes, modules — through narrative and example rather than reference
- The cartoon segments aren't just stylistic: they lower the cognitive load between code examples and create memorable anchors
- _why was prolific across Ruby tools, libraries, and writing; the Poignant Guide is the most famous artifact of that era
- Passed around as a shared cultural reference: "have you read the Poignant Guide?" was a common Ruby community touchstone
- Mislav's mirror kept the guide alive after _why's departure — a community archiving effort before GitHub made that easy
