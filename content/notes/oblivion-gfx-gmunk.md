## Summary

GMUNK (Brad Munkowitz) is a motion designer and creative director known for designing the screen graphics and HUD elements in high-profile sci-fi films. This portfolio page covers his work on the 2013 film *Oblivion* (directed by Joseph Kosinski), which he also worked with on *Tron: Legacy*. The graphics include helmet HUDs, tactical displays, data visualizations, and the ambient interface elements that define the film's visual language.

Film UI design is a specialized discipline that differs fundamentally from product design: it doesn't need to be usable — it needs to be legible, visually coherent, and narratively appropriate. The displays in Oblivion communicate "advanced drone maintenance pilot" without needing to function as real interfaces. Munkowitz's work on these films influenced the aesthetic vocabulary of diegetic interface design — interfaces that exist within the story world rather than as overlaid HUD elements — which became a significant trend in film and game design through the 2010s.

The broader GMUNK site documents work across commercial, interactive, and film contexts, but the film GFX work is the most widely referenced. Along with Ash Thorp and others, he's part of a generation of designers who defined what near-future interface looks like — an aesthetic that influenced not just sci-fi films but real product design (flat, data-dense, high contrast, monochrome with accent colors). Designers working on medical visualization, data dashboards, or control systems UI often look to this design tradition for inspiration.

## Key points

- GMUNK designed the HUD and screen graphics for *Oblivion* (2013) — helmet displays, tactical data, ambient interfaces.
- Diegetic interface design: UI elements that exist within the story world; must read clearly on screen without needing to be usable.
- Previously designed the interfaces for *Tron: Legacy* (2010) — the defining grid aesthetic.
- Film UI as a distinct practice: legibility and visual coherence matter; functionality doesn't.
- Influential on the broader "near-future interface" aesthetic that permeated both sci-fi and real product design in the 2010s.
- Reference for designers working on dashboards, data visualization, or any high-density information display wanting that aesthetic.
