## Summary

Mozilla OpenNews (Source) covered the data journalism work done around the 2012 London Olympics, examining how journalists and developers combined open data, data visualization, and rapid iteration under deadline pressure. The data olympics framing captures a key reality: high-profile events with rich public datasets and a global audience are an accelerant for data journalism craft.

The London Olympics were unusually data-rich: athlete stats, event schedules, medal tables, historical records, crowd data, and social media signals were all available. The teams that "won" the data olympics were those who could ingest, clean, and visualize this data faster than competitors — meaning the tooling (Python scripts, D3.js charts, public APIs) mattered as much as editorial judgment.

This represents the early crystallization of what would become the standard data journalism stack: Python for data wrangling, SQL for querying, and D3.js or Tableau for visualization. The time pressure of live events forced teams to build reusable pipelines rather than one-off scripts.

## Key points

- Major events with public datasets (Olympics, elections) are proving grounds for data journalism workflows
- Speed matters: the team that deploys a clean visualization first sets the narrative frame
- Open data from official sources (IOC stats, athlete databases) combined with social media data unlocked richer stories
- Reusable data pipelines — not one-off scripts — are what let teams scale coverage across multiple events
- Mozilla OpenNews (now OpenNews) was a key node connecting newsroom data journalists during this period
