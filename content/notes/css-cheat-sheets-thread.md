## Summary

This Twitter thread by @prathkum (Pratham Kumar) shares visual cheat sheets for CSS and web development concepts — the kind of quick-reference cards that are useful when you know a concept but can't remember the exact syntax. The format is image-based cards covering CSS selectors, flexbox, CSS Grid, CSS animations, and HTML elements.

Pratham Kumar became well-known on Twitter in 2020-2021 for creating visually appealing, color-coded reference cards for web development topics. The cheat sheets work as memory aids rather than learning resources — you need to understand the concepts to use them effectively, but having the syntax in a single visual reference saves time compared to checking documentation.

Flexbox and CSS Grid are the two cheat sheets most worth bookmarking: both have non-obvious property names (`justify-content` vs `align-items` and their behavior difference between flex and grid contexts), and even experienced developers benefit from having the alignment model in a visual format.

## Key points

- Visual cheat sheets by @prathkum — color-coded reference cards for CSS, HTML, flexbox, CSS Grid.
- Flexbox reference: main axis vs. cross axis, `justify-content` / `align-items` / `align-content` distinctions.
- CSS Grid: `grid-template-columns`, `fr` unit, `grid-area` naming — more spatial than flexbox.
- Format is image cards on Twitter — saved for quick visual reference, not deep learning.
- Context: 2021 Twitter had a thriving #devtwitter community creating educational visual content.
