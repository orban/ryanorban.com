## Summary

"Happy Healthy Hungry" (h3) is an IPython notebook by Jason Denner (Jay-Oh-eN) from the Zipfian Academy cohort, published via nbviewer and shared by Fernando Perez (IPython's creator). It analyzes San Francisco restaurant health inspection data to explore neighborhood patterns in food safety, combining data wrangling, geospatial visualization, and statistical analysis into a single, reproducible narrative.

The notebook format was itself noteworthy: this was 2013, when IPython notebooks (now Jupyter notebooks) were just establishing the computational narrative format — code, output, prose, and visualizations interleaved in a document you could share and re-run. The sharing via nbviewer (which renders notebooks as static HTML) made this accessible to non-programmers.

Zipfian Academy was one of the first data science bootcamps (San Francisco, founded 2013), and this notebook was part of a graduation showcase demonstrating what practitioners could build with a few months of training. The SF restaurant health data was an early example of useful city open data.

## Key points

- IPython notebook (now Jupyter) as a "computational narrative" format: code + output + prose in one shareable document.
- San Francisco restaurant health inspection data as a case study — an early city open data dataset.
- Shared by Fernando Perez (IPython creator) — signal that the Zipfian work had reached the broader Python scientific community.
- Zipfian Academy: one of the first data science bootcamps; graduation showcase projects like this helped establish the bootcamp → portfolio → job pipeline.
- nbviewer: the sharing mechanism that made IPython notebooks accessible before GitHub rendered them natively.
- Geospatial + statistical analysis of neighborhood restaurant patterns — neighborhood-level public health variation.
