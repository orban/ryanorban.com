## Summary

Defined.fi provides real-time price charts and trading analytics for DeFi token pairs — essentially TradingView-style charts for tokens that only trade on decentralized exchanges (DEXes) and don't appear on Binance or Coinbase. The core use case is tracking illiquid or new tokens on Uniswap, SushiSwap, PancakeSwap, and other AMMs.

For DeFi traders in 2022, the tooling gap was real: CoinGecko and CoinMarketCap aggregated price data but had poor chart quality for low-cap tokens. Dextools was the standard alternative but had a cluttered interface. Defined.fi took a cleaner approach — standard OHLCV candlestick charts, volume, and liquidity metrics for any token pair you could find on a supported DEX.

The analytics layer beyond basic charting: liquidity depth (how much slippage a given trade size would produce), holder distribution (wallet concentration analysis useful for identifying potential rug pull risk), recent transaction history with wallet labels, and trending tokens across chains. For active on-chain trading in the 2021-2022 DeFi boom, this was the kind of real-time signal tool that institutional DeFi desks would use alongside custom indexers.

## Key points

- Real-time OHLCV charts for any DEX token pair across Ethereum, BSC, Polygon, Avalanche, and others
- Liquidity depth visualization: shows the cost of large trades in slippage, essential for any meaningful position sizing
- Holder analysis: wallet concentration data helps identify rug pull risk in new token launches
- Competes with Dextools, GeckoTerminal, and DexScreener — most grew rapidly in the DeFi summer era
- Primary use case: tracking tokens that don't appear on CEXs yet, used by DeFi traders and protocol researchers
